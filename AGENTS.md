Full docs in [`docs/`](docs/). Use the **`docs_lookup`** skill/rule to navigate it before answering conceptual questions. ## Testing

Green unit tests are **necessary but not enough**: the prototype's trade screen crash (B22) lived with all tests green. Before calling a gameplay/UI/prompt change done, run a **live playtest** following the **`playtest`** skill ([.claude/skills/playtest/SKILL.md](.claude/skills/playtest/SKILL.md)): gdUnit4 green, backend pytest green, then `python tools/godot_playtest.py` (and `--scenario offline` when connection handling changed, `--scenario live --real` after prompt or agent changes), then read `build/playtest/*/report.txt` and the screenshots. Prompt changes also get the golden scenarios (`--repeat 3` before conclusions: the model varies ±2 per run).

Never print or log keys from `.env`.

**Version:** the project version lives in the root `VERSION` file (and `config/version` in `game/project.godot`). CI requires every PR to bump it and to update `RELEASE_NOTES.md`. Every version ends with `python tools/build_game.py` after the tests are green: the author plays that build. The game starts the frozen `server.exe` itself on the player's OpenRouter key from the settings; an address in the settings means an external server with its token ([ADR-0014](docs/tech/adr/0014-embedded-master-server.md)).

## Conventions

- Game text, prompts, lore — Russian. Code identifiers and code comments — English.
- LLM output is always Pydantic-typed (`llm_server/src/llm_server/protocol.py`); don't parse free text. New agents use **Pydantic AI**.
- The engine decides, the LLM narrates (ADR-0008): any change of the world goes through an engine call (`engine.check`, `engine.validate` of an effect) or a deterministic button of the client. Experience is never an LLM effect: only combat and pack quests (`XpRules`).
- Minimum duplication of code and of mechanics. Before writing a rule, a helper or a window part, look for one that already does it (the table «Where to add things» below, `docs/design/concepts.md`) and reuse it, widening it with a parameter or a row of data when it falls short. Never a second copy beside it: no parallel road for the hero and for NPCs, no `player_*` beside `_enemy_*`, no private reader of an item or a spell beside the rule's own, no mechanic that lives only in the master's words when the engine has a road for it. A bug seen again means one shared place for it, not another local fix; when two copies are found, merge them into one and remove the other.
