# Иконки и портреты на Anima

Иконки игры (вещи, заклинания, умения классов, черты рас, состояния, действия боя, группы инвентаря) рисует Anima на своём Forge. Стиль: один плоский силуэт в несколько цветов на ровном фоне; фон вырезается в прозрачный PNG 128×128. Это часть v0.8.4.43 «Лёгкий и понятный интерфейс» ([роадмап](../../docs/production/roadmap.md)).

| Файл | Что | Где запускается |
|---|---|---|
| `make_jobs.py` | собирает список иконок из данных игры → `jobs/icons.json` | в репо |
| `subjects.json` | что показывает каждая иконка: английские теги и одно предложение, по `<вид>/<id>` | правится руками |
| `jobs/icons.json` | готовые задания для генератора | копируется на сервер |
| `portraits.json` | внешность людей для портретов: волосы, глаза, кожа, борода, одежда по расам, полу и возрасту | правится руками |
| `jobs/portraits.json` | задания портретов: люди и монстры | копируется на сервер |
| `anima_gen.py` | рисует на Forge, вырезает фон, собирает листы; нужен только Python 3.9+ и Pillow | на машине с Forge |

## 1. Список иконок (в репо)

```bash
python tools/anima/make_jobs.py --describe      # модель пишет описания, которых ещё нет (центы, ключ из .env)
python tools/anima/make_jobs.py                 # только пересобрать jobs/icons.json из subjects.json
python tools/anima/make_jobs.py --describe --redo items/chain_mail,spells/fireball   # переписать эти описания
```

Описание, которое уже есть в `subjects.json`, не перезаписывается: если иконка вышла не тем предметом, поправь её `tags` / `sentence` руками и перерисуй только её. Фон — тёмный; `dark: true` (или «black» / «dark grey» в предложении) — предмет тёмный, его рисуют на сером, чтобы вырезка не съела край; `key` в описании задаёт фон руками (`dark`, `grey`, `white`, `green`).

## 2. Рисование (на сервере с Forge)

Forge должен быть запущен с `--api`, в нём чекпойнт `anima-aesthetic-v1.1` и модули `qwen_image_vae.safetensors`, `qwen_3_06b_base.safetensors`.

```bash
scp -r tools/anima user@server:~/anima          # или git pull на сервере
ssh user@server
cd ~/anima && pip install pillow
nohup python3 anima_gen.py jobs/icons.json > anima.log 2>&1 &
tail -f anima.log                               # [12/1856] items/longsword #1 19s, left ~9.8 h
```

Ноутбук можно выключать: рисует сервер. Остановленный прогон (`kill`, перезагрузка) запускается той же командой и продолжает с недорисованных — готовые файлы он пропускает.

После `git pull` с поправленными описаниями та же команда перерисует только те иконки, чьё описание изменилось: рядом с каждым вариантом лежит промт, по которому он нарисован (`variants/<id>__<n>.txt`).

Параметры (по умолчанию — в скобках):

| Ключ | Что |
|---|---|
| `--url` (`http://127.0.0.1:7860`) | адрес Forge |
| `--checkpoint` (`anima-aesthetic`) | часть названия чекпойнта |
| `--side` (768), `--steps` (20), `--cfg` (4.5), `--sampler` (`ER SDE`) | генерация; карточка Anima: 512–1536 px, CFG 4–5, ER SDE |
| `--seeds` (`11,22`) | по варианту на сид |
| `--bg` (`dark`) | фон, где задание не задало свой: `dark`, `grey`, `white`, `green` |
| `--style` (`flat`) | стиль иконки: `flat` — плоский минимализм в `out/`, `painted` — живописный в `out_painted/` (раздел 6) |
| `--recut` | перерезать варианты из сырых кадров, ничего не рисуя |
| `--only items,spells` | только эти виды |
| `--ids longsword,fireball --redraw` | перерисовать эти |
| `--sheets` | только собрать листы из нарисованного |
| `--pick longsword=2` | иконкой стать варианту 2 |

## 3. Что получается

```
out/<вид>/raw/<id>__<сид>.png      кадр как его нарисовал Forge
out/<вид>/variants/<id>__<n>.png   вырезанный вариант n, 128 px
out/<вид>/<id>.png                 иконка: вариант 1 или выбранный --pick
out/<вид>/sheet_<вид>_<стр>.png    листы: строка — иконка, столбец — вариант, на тёмной ячейке
```

Папка `out/` в git не идёт (сотни мегабайт): её забирают с сервера к себе, в `tools/anima/out/`.

## 4. В игру

Какой вариант каждой иконки идёт в игру, записано в `picks.json`: `variant` — иконки, у которых лучше не первый вариант, `redo` — неудачные в обоих, их игра показывает заготовкой, пока описание не поправят и не перерисуют. Файл в репо, так что выбор не теряется, когда `out/` снова приходит с сервера.

```bash
python tools/anima/install.py            # out/<вид>/variants/<id>__<n>.png → game/assets/icons/<вид>/<id>.png
"$GODOT" --headless --path game --import
```

Порядок: смотришь листы, вписываешь в `picks.json` лучшие варианты и неудачные; неудачным правишь описание в `subjects.json`, `make_jobs.py`, та же команда рисования (перерисуются только они), убираешь их из `redo`, `install.py`. Заменить любую иконку можно своим PNG с тем же именем.

## 5. Портреты

Портрет в жетоне, колонке отряда, очереди боя и карточке существа вместо первой буквы имени (пункт роадмапа v0.8.4.43). Стиль выбран с автором 2026-11-11 на пробе: бюст в мягкой живописной манере на тёмном приглушённом фоне; в игру идёт **лицо, вырезанное из бюста** (кроп `FACE` в `anima_gen.py`), 256 px WebP — в круге 64 px бюст превращается в точку, лицо читается. Сам бюст 768 px остаётся в `out/<вид>/raw/` на будущее для карточки.

- **Люди** — по расе (`races.json`), полу и возрасту (`rules.body.age`), без классов: 9 × 2 × (6 возрастов × 5 вариантов + ребёнок × 1) = **558**. Внешность каждого варианта собирается из таблиц `portraits.json` без модели: перемешивание по расе, полу и возрасту постоянное, так что 5 вариантов отличаются волосами, глазами, кожей, одеждой и бородой и не меняются от прогона к прогону. У расы свои слова и свои пробелы: у драконорождённого нет волос — чешуя, у эльфа нет бороды, у гнома и полурослика — «взрослое лицо», чтобы не вышел ребёнок.
- **Дети и подростки** — с негативом картинок событий против детей (`loli, shota, child`, v0.8.4.42.22): ребёнку из него убирается только `child` (иначе ребёнка не нарисовать), добавляются `minor_neg` — ни декольте, ни открытой одежды, ни косметики; `safe` в начале любого портрета.
- **Монстры** — 150 шаблонов, которые игра читает (без `rules.off.monsters`), по 5 вариантов-сидов = **750**. Описание пишет модель один раз по шаблону SRD (`portraits/monsters/<id>` в `subjects.json`, правится руками); обычный человек среди шаблонов (разбойник, стражник, жрец — `person: true`) в нечётных вариантах мужчина, в чётных женщина.

```bash
python tools/anima/make_jobs.py --portraits --describe     # описания монстров, которых ещё нет (центы), → jobs/portraits.json
nohup python3 anima_gen.py jobs/portraits.json --steps 24 > portraits.log 2>&1 &   # на сервере: 1308 кадров, ~8 ч
python3 anima_gen.py jobs/portraits.json --ids human/male/young,goblin --first 2 --steps 24   # проба: два варианта
python3 anima_gen.py jobs/portraits.json --recut   # перерезать все варианты из сырых кадров (сменили FACE), без рисования
python tools/anima/install.py --jobs tools/anima/jobs/portraits.json   # → game/assets/portraits/
```

Файлы в игре — `game/assets/portraits/people/<раса>/<пол>/<возраст>__<n>.webp` и `game/assets/portraits/monsters/<id>__<n>.webp`; в игру идут все варианты (вариант человека выбирает игра). Неудачный — в `redo` файла `picks.json` как `portraits/people/human/male/young__3`: игра покажет на его месте букву, пока его не перерисуют.

## 6. Живописные иконки

Плоский минимализм перестал вписываться рядом с портретами и живописным интерфейсом (автор, 2026-11-11). `--style painted` рисует те же описания из `subjects.json` **семействами, как в BG3** ([разбор стиля](../../docs/design/ux/bg3-icons.md), `FAMILY` в `anima_gen.py`):

| Семейство | Виды | Как | Вырез |
|---|---|---|---|
| `object` | `items` и всё, чего нет ниже | живописный предмет: мягкая светотень, свет слева сверху, на тёмном фоне (`PAINTED_*`) | фон вырезается, как у плоских |
| `glyph` | `spells`, `features`, `acts`, `traits` | яркий светящийся знак на плитке шершавого камня, плитка на чёрном (`GLYPH_*`, выбор автора 2026-11-11) | чёрное вырезается, углы плитки прозрачные; камень во весь кадр — квадрат целиком |
| `medal` | `conditions` | тот же знак на плитке | плитка, обрезанная кругом по своей рамке |
| `relief` | `ui`, `groups` | серебряная выпуклая эмблема (`RELIEF_*`; проба 2026-11-11: модель рисует живописную вещь с серебряной деталью) | как у вещи |
| `flat` | `marks/*` | плоский минимализм, как без `--style` | как у вещи |

Плитка глифа обычно висит на ровном фоне (чёрном, изредка белом) и вырезается; если камень занял весь кадр, край кадра пёстрый, и плитка остаётся квадратом (`FLAT`). Рисуется в `out_painted/`, плоские иконки в `out/` и в игре остаются, пока живописные не выбраны.

```bash
# на сервере, на ночь: предметы и заклинания — 593 иконки × 2 варианта, ~6 ч при 20 шагах; остановленный прогон продолжается той же командой
nohup python3 anima_gen.py jobs/icons.json --style painted --steps 20 --only items,spells > painted.log 2>&1 &
# следующей ночью: умения, действия, состояния — 284 × 2, ~3 ч
nohup python3 anima_gen.py jobs/icons.json --style painted --steps 20 --only features,acts,conditions > painted.log 2>&1 &
# проба семейства на нескольких: по одному варианту
python3 anima_gen.py jobs/icons.json --style painted --ids fireball,bless,longsword --first 1
# дома: out_painted/ с сервера в tools/anima/out_painted/, выбор вариантов — в picks_painted.json
python tools/anima/install.py --out tools/anima/out_painted --picks tools/anima/picks_painted.json
```

## 7. Элементы интерфейса

Рамки окон, кнопки, ячейки панели действий — своим рисунком в стиле портретов (проба 2026-11-11). Геометрию рисует код (`ui/guides.py`: глубина и линии), Anima раскрашивает материал через ControlNet LLLite (`ui/paint.py`: `anima-lllite-depth-1` + `anima-lllite-lineart-1`), `ui/mock.py` режет на 9 частей и собирает макет с кнопкой в четырёх состояниях. Чужой арт (BG3 и др.) опорой не берём. Второй вызов LLLite ломает модель Forge (500 «'NoneType' object is not callable»): `paint.py` выгружает чекпойнт после каждого кадра — не запускать рядом с другим заданием.

```bash
python tools/anima/ui/guides.py      # → out_ui/guides/
python tools/anima/ui/paint.py       # → out_ui/raw/<part>_<material>_<seed>.png, ~40 с кадр
python tools/anima/ui/mock.py        # → out_ui/mock/
```

## Время

Замер на нашем Forge: 768 px / 20 шагов — 18,7 с на картинку (1024 px / 30 шагов — 50 с, на 128 px разницы не видно), первая дольше — загрузка модели. 928 иконок × 2 варианта — около 9,6 часа.

## Почему такой промт

Сравнение 2026-11-10 (один сид, одно изменение за раз): тёмный фон без своего тега рисует предмет крупнее и смелее всего; сплошной зелёный, серый или пурпурный фон уменьшает предмет и портит абстрактные эмблемы, «dark outline» даёт толстые чёрные контуры. Поэтому фон тёмный, «two or three colors», без обводки.
