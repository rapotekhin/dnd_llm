# Иконки и портреты на Anima

Иконки игры (вещи, заклинания, умения классов, черты рас, состояния, действия боя, группы инвентаря) рисует Anima на своём Forge. Стиль: один плоский силуэт в несколько цветов на ровном фоне; фон вырезается в прозрачный PNG 128×128. Это часть v0.8.4.43 «Лёгкий и понятный интерфейс» ([роадмап](../../docs/production/roadmap.md)).

| Файл | Что | Где запускается |
|---|---|---|
| `make_jobs.py` | собирает список иконок из данных игры → `jobs/icons.json` | в репо |
| `subjects.json` | что показывает каждая иконка: английские теги и одно предложение, по `<вид>/<id>` | правится руками |
| `jobs/icons.json` | готовые задания для генератора | копируется на сервер |
| `portraits.json` | внешность людей для портретов: волосы, глаза, кожа, борода, одежда по расам, полу и возрасту | правится руками |
| `jobs/portraits.json` | задания портретов: люди и монстры | копируется на сервер |
| `anima_gen.py` | рисует на Forge, вырезает фон, собирает листы; нужен только Python 3.9+ и Pillow | на машине с Forge |

## 1. Список иконок (в репо)

```bash
python tools/anima/make_jobs.py --describe      # модель пишет описания, которых ещё нет (центы, ключ из .env)
python tools/anima/make_jobs.py                 # только пересобрать jobs/icons.json из subjects.json
python tools/anima/make_jobs.py --describe --redo items/chain_mail,spells/fireball   # переписать эти описания
```

Описание, которое уже есть в `subjects.json`, не перезаписывается: если иконка вышла не тем предметом, поправь её `tags` / `sentence` руками и перерисуй только её. Фон — тёмный; `dark: true` (или «black» / «dark grey» в предложении) — предмет тёмный, его рисуют на сером, чтобы вырезка не съела край; `key` в описании задаёт фон руками (`dark`, `grey`, `white`, `green`).

## 2. Рисование (на сервере с Forge)

Forge должен быть запущен с `--api`, в нём чекпойнт `anima-aesthetic-v1.1` и модули `qwen_image_vae.safetensors`, `qwen_3_06b_base.safetensors`.

```bash
scp -r tools/anima user@server:~/anima          # или git pull на сервере
ssh user@server
cd ~/anima && pip install pillow
nohup python3 anima_gen.py jobs/icons.json > anima.log 2>&1 &
tail -f anima.log                               # [12/1856] items/longsword #1 19s, left ~9.8 h
```

Ноутбук можно выключать: рисует сервер. Остановленный прогон (`kill`, перезагрузка) запускается той же командой и продолжает с недорисованных — готовые файлы он пропускает.

После `git pull` с поправленными описаниями та же команда перерисует только те иконки, чьё описание изменилось: рядом с каждым вариантом лежит промт, по которому он нарисован (`variants/<id>__<n>.txt`).

Параметры (по умолчанию — в скобках):

| Ключ | Что |
|---|---|
| `--url` (`http://127.0.0.1:7860`) | адрес Forge |
| `--checkpoint` (`anima-aesthetic`) | часть названия чекпойнта |
| `--side` (768), `--steps` (20), `--cfg` (4.5), `--sampler` (`ER SDE`) | генерация; карточка Anima: 512–1536 px, CFG 4–5, ER SDE |
| `--seeds` (`11,22`) | по варианту на сид |
| `--bg` (`dark`) | фон, где задание не задало свой: `dark`, `grey`, `white`, `green` |
| `--style` (`flat`) | стиль иконки: `flat` — плоский минимализм в `out/`, `painted` — живописный в `out_painted/` (раздел 6), `lines` — тонкие линии в рамке кодом в `out_lines/` (раздел 7) |
| `--recut` | перерезать варианты из сырых кадров, ничего не рисуя |
| `--only items,spells` | только эти виды |
| `--ids longsword,fireball --redraw` | перерисовать эти |
| `--sheets` | только собрать листы из нарисованного |
| `--pick longsword=2` | иконкой стать варианту 2 |

## 3. Что получается

```
out/<вид>/raw/<id>__<сид>.png      кадр как его нарисовал Forge
out/<вид>/variants/<id>__<n>.png   вырезанный вариант n, 128 px
out/<вид>/<id>.png                 иконка: вариант 1 или выбранный --pick
out/<вид>/sheet_<вид>_<стр>.png    листы: строка — иконка, столбец — вариант, на тёмной ячейке
```

Папка `out/` в git не идёт (сотни мегабайт): её забирают с сервера к себе, в `tools/anima/out/`.

## 4. В игру

Какой вариант каждой иконки идёт в игру, записано в `picks.json`: `variant` — иконки, у которых лучше не первый вариант, `redo` — неудачные в обоих, их игра показывает заготовкой, пока описание не поправят и не перерисуют. `overlay` — знак кодом поверх (`overlays.py`: пацифик, `strike` — красная черта через всю иконку), `same` — иконка с выбранного варианта другой (`"features/domain_spells_2": "features/domain_spells_1"`), `drawn` — иконка целиком кодом (`overlays.ICONS`: `d20`, `sheet_lines` — где модель заливает геометрию); на странице выбора такие не показывают. Файл в репо, так что выбор не теряется, когда `out/` снова приходит с сервера.

```bash
python tools/anima/install.py            # out/<вид>/variants/<id>__<n>.png → game/assets/icons/<вид>/<id>.png
"$GODOT" --headless --path game --import
```

Порядок: смотришь листы, вписываешь в `picks.json` лучшие варианты и неудачные; неудачным правишь описание в `subjects.json`, `make_jobs.py`, та же команда рисования (перерисуются только они), убираешь их из `redo`, `install.py`. Заменить любую иконку можно своим PNG с тем же именем.

## 5. Портреты

Портрет в жетоне, колонке отряда, очереди боя и карточке существа вместо первой буквы имени (пункт роадмапа v0.8.4.43). Стиль выбран с автором 2026-11-11 на пробе: бюст в мягкой живописной манере на тёмном приглушённом фоне; в игру идёт **лицо, вырезанное из бюста** (кроп `FACE` в `anima_gen.py`), 256 px WebP — в круге 64 px бюст превращается в точку, лицо читается. Сам бюст 768 px остаётся в `out/<вид>/raw/` на будущее для карточки.

- **Люди** — по расе (`races.json`), полу и возрасту (`rules.body.age`), без классов: 9 × 2 × (6 возрастов × 5 вариантов + ребёнок × 1) = **558**. Внешность каждого варианта собирается из таблиц `portraits.json` без модели: перемешивание по расе, полу и возрасту постоянное, так что 5 вариантов отличаются волосами, глазами, кожей, одеждой и бородой и не меняются от прогона к прогону. У расы свои слова и свои пробелы: у драконорождённого нет волос — чешуя, у эльфа нет бороды, у гнома и полурослика — «взрослое лицо», чтобы не вышел ребёнок.
- **Дети и подростки** — с негативом картинок событий против детей (`loli, shota, child`, v0.8.4.42.22): ребёнку из него убирается только `child` (иначе ребёнка не нарисовать), добавляются `minor_neg` — ни декольте, ни открытой одежды, ни косметики; `safe` в начале любого портрета.
- **Монстры** — 150 шаблонов, которые игра читает (без `rules.off.monsters`), по 5 вариантов-сидов = **750**. Описание пишет модель один раз по шаблону SRD (`portraits/monsters/<id>` в `subjects.json`, правится руками); обычный человек среди шаблонов (разбойник, стражник, жрец — `person: true`) в нечётных вариантах мужчина, в чётных женщина.

```bash
python tools/anima/make_jobs.py --portraits --describe     # описания монстров, которых ещё нет (центы), → jobs/portraits.json
nohup python3 anima_gen.py jobs/portraits.json --steps 24 > portraits.log 2>&1 &   # на сервере: 1308 кадров, ~8 ч
python3 anima_gen.py jobs/portraits.json --ids human/male/young,goblin --first 2 --steps 24   # проба: два варианта
python3 anima_gen.py jobs/portraits.json --recut   # перерезать все варианты из сырых кадров (сменили FACE), без рисования
python tools/anima/install.py --jobs tools/anima/jobs/portraits.json   # → game/assets/portraits/
```

Файлы в игре — `game/assets/portraits/people/<раса>/<пол>/<возраст>__<n>.webp` и `game/assets/portraits/monsters/<id>__<n>.webp`; в игру идут все варианты (вариант человека выбирает игра). Неудачный — в `redo` файла `picks.json` как `portraits/people/human/male/young__3`: игра покажет на его месте букву, пока его не перерисуют.

## 6. Живописные иконки

Плоский минимализм перестал вписываться рядом с портретами и живописным интерфейсом (автор, 2026-11-11). `--style painted` рисует те же описания из `subjects.json` **семействами, как в BG3** ([разбор стиля](../../docs/design/ux/bg3-icons.md), `FAMILY` в `anima_gen.py`):

| Семейство | Виды | Как | Вырез |
|---|---|---|---|
| `object` | `items`, `groups` | живописный предмет: мягкая светотень, свет слева сверху, на тёмном фоне (`PAINTED_*`) | на сервере — цветом, как у плоских; дома — **`matte.py`** (BiRefNet на видеокарте): вещь по своей рамке |
| `glyph` | `spells` | яркий светящийся знак на плитке шершавого камня, плитка на чёрном (`GLYPH_*`, выбор автора 2026-11-11) | по форме плитки: выпуклая оболочка, выпрямлена, обрезана по своей рамке; камень во весь кадр — квадрат целиком |
| `plate` | `features` | тот же знак на пластине светлой стали с синим отливом и заклёпками по углам (`PLATE_*`, выбор автора 2026-11-12): умение не спутать с заклинанием | как `glyph` |
| `ink` | `acts` | жест руками в три четверти или предмет — несколько грубых штрихов тёмной тушью без заливки на той же стальной пластине (`INK_*`, выбор автора 2026-11-12, приём действий BG3); **рисует FLUX** (`--backend openrouter`): жесты у него читаются, у Anima — кулак и молитва (автор, 2026-11-12) | как `glyph` |
| `bronze` | `traits` | тот же знак, что у заклинания, на пластине тёплой бронзы с патиной и заклёпками (`BRONZE_*`, выбор автора 2026-11-12): черта расы не спутается со сталью умений и действий | как `glyph` |
| `medal` | `conditions` | простой значок: тонкое золотое кольцо, тёмное ровное поле, одна плоская эмблема своего яркого цвета с тёмным контуром (`MEDAL_*`, выбор автора 2026-11-12: плитка в круге и чеканная монета — «не очень») | как `glyph`, потом круг по своей рамке |
| `gold` | `ui` | рисунок тонкими бледно-золотыми линиями на чёрном, одни контуры без заливки (`GOLD_*`, выбор автора 2026-11-12: кнопки в стиле интерфейса «линии»); цвета сюжета выкидываются из промта (`uncolour`): «бледная роза компаса» выходила залитой | яркость — прозрачность, рисунок перекрашен в одно золото и вписан в квадрат с одинаковым полем (`gold`) |
| `flat` | `marks/*` | плоский минимализм, как без `--style` | цветом |

Интерфейс и группы пробовали «серебряным рельефом», как навыки BG3: модель нарисовала живописные вещи с серебряной деталью, автор взял вещи (2026-11-11); кнопки интерфейса с 2026-11-12 — золотые линии, как сам интерфейс. Действия тем же золотом пробовали: предметы (меч, сапог, кинжал) выходят, жесты рук — нет, автор оставил тушь на стали. Рисуется в `out_painted/`, плоские иконки в `out/` и в игре остаются, пока живописные не выбраны.

**Вырез.** Цветом (заливкой от края) режется только ровный фон. Живописный фон бурый, с градиентом и мягкой тенью: цвет ел тёмные части вещи (кольчуга, рукоять) и оставлял тень, а у плиток заходил в чёрные трещины камня. Поэтому плитка режется по своей форме (`tile` в `anima_gen.py`, работает и на сервере): фон — гладкая поверхность цвета по краю кадра (градиент под пластиной не остаётся каймой), камень во весь кадр узнаётся по текстуре вне плитки и остаётся целым. Вещь — моделью дома:

```bash
# один раз: своё окружение с torch (CUDA) рядом, не в venv репо; модель (444 МБ) скачается в .venv-matte/birefnet
venv/Scripts/uv.exe venv --python <Python 3.10> tools/anima/.venv-matte
venv/Scripts/uv.exe pip install --python tools/anima/.venv-matte/Scripts/python.exe torch torchvision --index-url https://download.pytorch.org/whl/cu128
venv/Scripts/uv.exe pip install --python tools/anima/.venv-matte/Scripts/python.exe "transformers<5" timm kornia einops pillow huggingface_hub
# после каждого прогона с сервера: вещи — моделью (~0,7 с кадр на RTX 3050 Ti), плитки — по форме, листы заново
tools/anima/.venv-matte/Scripts/python.exe tools/anima/matte.py tools/anima/jobs/icons.json --only items,ui,groups
python tools/anima/anima_gen.py tools/anima/jobs/icons.json --style painted --only spells,features,acts,traits,conditions --recut
python tools/anima/anima_gen.py tools/anima/jobs/icons.json --style painted --sheets
```

**Через OpenRouter** (`--backend openrouter`, модель `--model`, по умолчанию `black-forest-labs/flux-3-image-klein`, ~$0.009 кадр): тот же промт семейства, без негатива (у FLUX его нет), по `--parallel` 4 кадра сразу, ключ `OPENROUTER_API_KEY` из окружения или `.env` репо. Своя папка `out_painted_flux/` и свой выбор `picks_flux.json`: варианты Anima не смешиваются. Сид OpenRouter принимает, но не держит — перерисованный вариант выйдет другой картинкой. Штамп хранит модель: другая модель — варианты перерисуются. Вырез тот же (`tile`, `medal`, `gold`; вещи — `matte.py` с `--out`). Проба 2026-11-12 на восьми действиях тем же промтом: FLUX понял жесты («ладонь сжимает предплечье», «сцепленные предплечья»), сталь у него темнее и ближе к фото; базовые действия рисует он (автор). Весь набор через него при желании: 1007 иконок × 2 ≈ $18, портреты 1308 ≈ $12; рамки интерфейса — нет, им нужен ControlNet.

```bash
python tools/anima/anima_gen.py tools/anima/jobs/icons.json --style painted --only acts --backend openrouter   # 34 × 2, ~5 мин, ~$0.6
python tools/anima/pick.py                     # http://127.0.0.1:8791/#acts
python tools/anima/install.py --out tools/anima/out_painted_flux --picks tools/anima/picks_flux.json --only acts
```

**Похожие.** Знаки, которые в 64 px путаются (огненный шар и огненная сфера, молния и ускорение, семь синих щитов), разводятся описанием по смыслу заклинания, не сидом; одинаковые по форме, но разные по цвету оставляем (автор, 2026-11-12).

```bash
# на сервере, на ночь: предметы и заклинания — 593 иконки × 2 варианта, ~6 ч при 20 шагах; остановленный прогон продолжается той же командой
nohup python3 anima_gen.py jobs/icons.json --style painted --steps 20 --only items,spells > painted.log 2>&1 &
# следующей ночью: умения, черты рас, состояния, группы — 302 × 2, ~3,3 ч (действия рисует FLUX, интерфейс — уже нарисован дома)
nohup python3 anima_gen.py jobs/icons.json --style painted --steps 20 --only features,traits,conditions,groups > painted.log 2>&1 &
# проба семейства на нескольких: по одному варианту
python3 anima_gen.py jobs/icons.json --style painted --ids fireball,bless,longsword --first 1
# дома: out_painted/<вид>/ с сервера в tools/anima/out_painted/; группы вырезать моделью
tools/anima/.venv-matte/Scripts/python.exe tools/anima/matte.py tools/anima/jobs/icons.json --only groups
# выбор вариантов в браузере: одна страница, кнопка на вид («Заклинания», «Действия», «Интерфейс»…), щелчок пишет
# вариант в выбор своей папки (picks_painted.json, у действий picks_flux.json); #acts — открыть на виде, ?ids=a,b — только перерисованные
python tools/anima/pick.py                     # http://127.0.0.1:8791/ ; --kind spells,acts — только эти виды
# плохи все варианты — галочка «перерисовать» под карточкой и пара слов, что не так: пишется в `redraw` того же файла
# выбора (это не `redo` — install.py ставит выбранный вариант, пока иконку не перерисуют); список отмеченных:
python tools/anima/pick.py --marked
python tools/anima/install.py --out tools/anima/out_painted --picks tools/anima/picks_painted.json
```

## 7. Иконки в стиле «линии»

Автор, 2026-11-12: заклинания, умения, действия и черты рас — как кнопки интерфейса (`ui`, семейство `gold`): тонкие линии на чёрном без заливки, вырезанные по яркости, но каждый вид в своей рамке и своём цвете. Это была проба стиля, автор взял его (в игре с v0.8.4.43.30): `--style lines` рисует в `out_lines/`, выбор — в `picks_lines_icons.json`; живописные иконки остаются в `out_painted/` и возвращаются в игру `install.py` с `picks_painted.json`.

| Вид | Рамка | Знак |
|---|---|---|
| `spells` | золотое кольцо в две линии с четырьмя ромбами, как кольцо портрета интерфейса | цветом своей школы: `tint` задания = `schools` из `game/data/icons.json` по `school_id` заклинания (`make_jobs.py`) |
| `features`, `acts` | золотой квадрат в две линии, как ячейка панели | золотом, у умений драконьего предка — цветом своего дракона, как у черт; действия рисует FLUX (`out_lines_flux/`), как и живописные: на пробе у Anima «Помочь» — молитвенно сложенные руки, у FLUX — сцепленные предплечья |
| `traits` | серебряный квадрат в две линии | серебром; у драконьих предков — цветом своего дракона (`tint` в `subjects.json`: десять черт отличаются только цветом) |

**Модель рисует только знак — белыми линиями на чёрном, без рамки** (семейство `sign`: промт кнопок `gold`, «white lines… nothing is drawn around it: no frame, no ring and no border», цвета сюжета выкинуты `uncolour`). Рамку и цвет кладёт код (`lines` в `anima_gen.py`, таблица `LINES`):
- геометрию модель портит: d20 залила, у медалей состояний торчащая стрелка рвала кольцо, у живописных плиток рамка выходила с наклоном и скруглением. Кодом рамка у всех 454 иконок одной толщины и одного поля, знак всегда внутри неё и не задевает её (вписан в круг по самой дальней точке рисунка, в квадрат — по рамке рисунка);
- цвет школы ровно тот, что у игры, а не «примерно розовый» модели; белые линии режутся по яркости чище цветных (тёмно-фиолетовая некромантия на чёрном почти не видна);
- рамку, цвета и толщину можно менять **без перерисовки**: `--recut` переделывает варианты из сырых кадров (`LINES`, `EDGE`/`OUTER`/`INNER`/`GAP`/`PAD`, `SIGN_LINE`); штамп варианта — только промт знака, так что смена цвета школы не перерисовывает кадр.

Линии знака модель рисует волосяными, а уменьшенные в рамку они пропадали рядом с её линией в 64 px: код доводит их до ширины `SIGN_LINE` (2 px на иконке 128, 1 px в 64), растягивая прозрачность (`bolder`).

```bash
# проба дома, по одному варианту: несколько каждого вида
python tools/anima/anima_gen.py tools/anima/jobs/icons.json --style lines --only spells,features,traits --ids fireball,shield,rage,darkvision --first 1
# на сервере, на ночь: заклинания, умения, черты — 420 иконок × 3 варианта = 1260 кадров, ~6,7 ч при 20 шагах
# (три варианта у стиля «линии» сами, `SEEDS`: 11, 22, 33 — так и --recut, и --sheets видят третий);
# остановленный прогон продолжается той же командой
nohup python3 anima_gen.py jobs/icons.json --style lines --steps 20 --only spells,features,traits > lines.log 2>&1 &
tail -f lines.log                              # [12/1260] spells/fireball #1 19s, left ~6.6 h
# дома: действия через FLUX — 34 × 3 = 102 кадра, ~7 мин, ~$0.9 → out_lines_flux/
python tools/anima/anima_gen.py tools/anima/jobs/icons.json --style lines --only acts --backend openrouter
# out_lines/ с сервера в tools/anima/out_lines/; выбор на той же странице — вкладки «· линии»
python tools/anima/pick.py                     # http://127.0.0.1:8791/#lines_spells; «Превью · линии» (#preview_lines) — экраны игры с выбранными иконками «линий»
python tools/anima/anima_gen.py tools/anima/jobs/icons.json --style lines --only spells,features,traits --recut   # другая рамка или цвет
python tools/anima/anima_gen.py tools/anima/jobs/icons.json --style lines --only acts --backend openrouter --recut
# в игру (v0.8.4.43.30) — поверх живописных; назад — те же команды с --out tools/anima/out_painted[_flux] и picks_painted.json / picks_flux.json
python tools/anima/install.py --out tools/anima/out_lines --picks tools/anima/picks_lines_icons.json --only spells,features,traits
python tools/anima/install.py --out tools/anima/out_lines_flux --picks tools/anima/picks_lines_icons.json --only acts
```

**Своё описание стиля.** Сюжет иконки общий с живописным стилем; где знак в «линиях» надо нарисовать иначе, у сюжета в `subjects.json` есть `lines`: `tags`, `sentence` и `people` (знак с людьми — орда, великан, рука: из головы промта уходит `no humans`). `make_jobs.py` переносит его в задание, `--style lines` рисует по нему, живописный вариант остаётся каким был (его штамп не меняется). Так переписаны 26 иконок по пометкам автора 2026-11-13: «больше не лучи» у лучей, божественное у кары, исполин и орда у охотника, драконы в профиль; их 78 кадров (~25 мин) рисует та же команда — она видит изменённый промт.

Проба 2026-11-12 (23 иконки, по варианту): знаки чистые, своих рамок модель не рисует. Цвета школ — как в игре: преобразование (охра) и вызов (янтарь) ближе всех к золоту кольца, но автор оставил их как есть (2026-11-12); другие цвета — только перерезкой.

## 8. Элементы интерфейса

Рамки окон, кнопки, ячейки, вкладки, подсказки и украшения — своим рисунком (пробы 2026-11-11 и 2026-11-12). Геометрию рисует код (`ui/guides.py`: глубина и линии, семьи направляющих heavy / thin / book / plate), Anima раскрашивает через ControlNet LLLite (`ui/paint.py`: `anima-lllite-depth-1` + `anima-lllite-lineart-1`; стиль — теги, фраза на каждую деталь, хвост, добавка к негативу и семья направляющих), `ui/mock.py` режет на 9 частей и собирает макет; `ui/preview.py` — экраны игры (экран, бой, снаряжение, книга заклинаний, лист) из деталей стиля «линии» по выбору `ui/picks_lines.json` и выбранных иконок; на странице выбора это вкладки «Рамки интерфейса» и «Превью». Чужой арт (BG3, Pathfinder) только смотрим, опорой не берём. Второй вызов LLLite ломает модель Forge (500 «'NoneType' object is not callable»): `paint.py` выгружает чекпойнт после каждого кадра — не запускать рядом с другим заданием.

Стили проб: `leather`, `wood` (тяжёлая кайма, первая проба), `lines` (тёмная панель в две тонкие золотые линии), `book` (лист пергамента с чернильной линией и кругами в углах), `plates` (сталь с заклёпками вокруг тёмного камня, как наши иконки). **Выбор автора 2026-11-12 — `lines`.** Его детали: `window`, `button`, `accent`, `tab`, `card`, `field`, `cell` — панели, режутся на 9 частей; `crest` (над заголовком окна), `divider`, `ring` (рамка портрета) — украшения на чёрном, кладутся целиком, их яркость — прозрачность.

Уроки проб:
- слово «window» модель рисует окном компьютера с заголовком и крестиком — в промте «panel»; «страница книги» — раскрытая книга, нужен «one flat sheet»;
- орнамент посередине края при нарезке растянется — только углы, а гербик над заголовком — отдельная деталь;
- вокруг рамки модель часто оставляет белое или чёрное поле: макет срезает белое заливкой от углов, скругление кнопки и вкладки — маской по направляющей; в игре там прозрачность;
- акцентную кнопку модель красит почти как обычную — тёплое золото темы кладётся кодом;
- нарисованная рамка бывает шире направляющей (у `plates` вдвое): поле нарезки (`mock.CUT`) подгоняется по кадру.

```bash
python tools/anima/ui/guides.py                                                  # → out_ui/guides/
python tools/anima/ui/paint.py --styles lines                                    # → out_ui/raw/<part>_<style>_<seed>.png, 20–90 с кадр
python tools/anima/ui/paint.py --styles lines --parts accent,tab,card,field,crest,divider,ring
python tools/anima/ui/mock.py --styles lines,book,plates                         # → out_ui/mock/mock_<style>_<seed>.png
python tools/anima/ui/preview.py                                                 # экраны по ui/picks_lines.json → out_ui/preview/
python tools/anima/ui/frames.py                                                  # выбранные детали в игру: game/assets/ui/frames/ по строкам `frames` в game/data/icons.json, потом --import
```

## Время

Замер на нашем Forge: 768 px / 20 шагов — 18,7 с на картинку (1024 px / 30 шагов — 50 с, на 128 px разницы не видно), первая дольше — загрузка модели. 928 иконок × 2 варианта — около 9,6 часа.

## Почему такой промт

Сравнение 2026-11-10 (один сид, одно изменение за раз): тёмный фон без своего тега рисует предмет крупнее и смелее всего; сплошной зелёный, серый или пурпурный фон уменьшает предмет и портит абстрактные эмблемы, «dark outline» даёт толстые чёрные контуры. Поэтому фон тёмный, «two or three colors», без обводки.
