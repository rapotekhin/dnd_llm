# Between the Rolls

Одиночная D&D 5e RPG на русском, где Мастером Подземелий выступает ЛЛМ.

Вы создаёте персонажа по правилам D&D 5e и попадаете в мир, который ЛЛМ ведёт как настольный мастер: описывает сцены, играет за NPC, просит броски и отвечает на любые действия — варианты на кнопках только подсказки, писать можно что угодно.

> 🎯 **Главный принцип:** ЛЛМ — мастер, а не движок. Броски, DC, деньги, предметы, переходы, найденное, сделки и опыт решает игровой движок; мастер просит проверку или предлагает последствие, а движок проверяет и применяет ([ADR-0008](docs/tech/adr/0008-engine-decides-llm-narrates.md)). Поэтому мир не «плывёт», а мастера нельзя уговорить выдать лишнее.

## Статус: v0.5.4

Перенос с pygame-прототипа на **Godot-клиент + Python-бэкенд мастера** закончен. Что уже можно делать:

- **Начать игру в своём мире.** Мир — пакет данных (мод); встроенный — «Сумеречная Марка»: пограничный городок Ольховый Брод, Пуща, старая застава и шахта. Стиль мастера (классический, литературный, сухой, ироничный) и границы контента — в новой игре.
- **Создать персонажа** по SRD 5e: 9 рас, 12 классов с подклассами, point buy, навыки, заклинания, снаряжение — или взять одного из 12 готовых героев мира.
- **Исследовать:** проверки навыков с картой броска (DC и кубик — у движка), повтор проваленного без изменений не работает, скрытое в комнатах находится Внимательностью и обыском, долгий отдых в безопасных местах, карта и журнал.
- **Разговаривать и торговать:** NPC отвечают в характере и помнят разговоры по сводкам; торговля — панель сделки с кошельками и запасами торговцев, торг Убеждением или Обманом.
- **Расти:** опыт за задания (и, с боем, за победы), повышение уровня до 5-го с выбором подкласса, характеристик и заклинаний.
- Сохранения в слоты и автосейв.

**Дальше** ([роадмап](docs/production/roadmap.md)) — M2 «Игровой цикл»: правила 5e до конца (траты ячеек, состояния, 0 HP, короткий отдых), минимальный бой и законченное приключение в Марке на 1–2 часа. Потом — меняющийся мир, тактический бой, рогалик-режим и генерация мира.

## Как запустить

Нужны [Godot 4.7](https://godotengine.org/), [uv](https://docs.astral.sh/uv/) и ключ [OpenRouter](https://openrouter.ai/) (ход стоит доли цента на модели по умолчанию).

1. Корневая `.env`:

   ```
   OPENROUTER_API_KEY=ваш_ключ
   LLM_SERVER_TOKEN=любая_строка
   ```

2. Сервер мастера:

   ```bash
   uv run --project llm_server python -m llm_server
   ```

3. Игра: открыть папку `game/` в редакторе Godot или

   ```bash
   godot --path game
   ```

   Адрес и токен сервера — «Настройки → Мастер» (по умолчанию локальный сервер). Без ключа сервер можно поднять с заглушкой хода: `LLM_SERVER_TURN_HANDLER=stub`. Сервер на VPS — [deploy.md](docs/tech/deploy.md).

## Структура репозитория

| Папка | Что |
|---|---|
| `game/` | Godot-клиент (GDScript): UI, состояние, правила 5e, сейвы, пакеты миров — [godot-client.md](docs/tech/godot-client.md) |
| `llm_server/` | бэкенд мастера: FastAPI + WebSocket (JSON-RPC), Pydantic AI, OpenRouter — [README](llm_server/README.md) |
| `contract/` | JSON Schema протокола Godot ↔ бэкенд |
| `tools/` | импорт SRD, проверка пакетов миров, живые плейтесты |
| `evals/` | «золотые» сценарии для проверки мастера |
| `infra/` | локальный `wss://` через Caddy |
| `docs/` | документация и ADR — старт с [docs/README.md](docs/README.md) |

Версия — в файле `VERSION`. Инструкции для ИИ-агентов и все команды — в [AGENTS.md](AGENTS.md).

## Тесты

- Godot: gdUnit4 (`game/test/`) — команда в [AGENTS.md](AGENTS.md#commands).
- Бэкенд: `cd llm_server && uv run pytest` (протокол, контракт, агент, промпты, проверка пакетов миров).
- Формат «золотых» сценариев: `pip install -r requirements-dev.txt && python -m pytest`.
- Живой плейтест — настоящая игра со скриншотами: `python tools/godot_playtest.py` (сценарии — скилл [playtest](.claude/skills/playtest/SKILL.md)).
- Проверка мастера на реальной модели: `uv run --project llm_server python -m llm_server.golden`.

**CI:** на pull request в `main` — тесты бэкенда, формат сценариев и проверка, что изменены `VERSION` и `RELEASE_NOTES.md`.
