# Pitch — Between the Rolls

## Одна фраза

**Между бросками** — одиночная D&D 5e RPG в открытом мире, где Мастера Подземелий заменяет ЛЛМ.

## Десять секунд

Ты создаёшь персонажа по правилам D&D 5e и попадаешь в мир, где ЛЛМ ведёт партию: описывает сцены, играет за NPC, назначает броски, реагирует на любые твои действия. Мир и события генерируются на ходу — это бесконечная песочница, где ты можешь делать что угодно, пока твой персонаж жив. Умер — начинай заново.

## Жанр

Текстовая RPG с элементами:
- **Open world** — мир бесконечен и генерируется на ходу
- **Sandbox** — нет навязанного сюжета, игрок решает, чем заниматься
- **Roguelike** — смерть персонажа окончательна
- **CRPG** — строгие правила D&D 5e под капотом

Графика: текст + аватарки. Это сознательный выбор для прототипа. Иллюстрации/тайлы могут появиться позже, **не меняя механик**.

## Уникальная фишка (USP)

Три кита, которые отличают игру от AI Dungeon, NovelAI, Friends&Fables и подобных:

1. **Безграничный open world с автогенерацией.** ЛЛМ не просто рассказывает — он создаёт NPC, локации и квесты через функции движка. Мир растёт по мере исследования.

2. **Полная свобода действий.** Игрок не ограничен заранее заготовленными выборами. ЛЛМ-ГМ интерпретирует любое действие игрока в рамках правил D&D 5e.

3. **ЛЛМ как ГМ, а не как движок.** ЛЛМ не «галлюцинирует» состояние мира — он вызывает Python-функции для всего: бросков, изменений инвентаря, создания сущностей. Состояние живёт в коде, не в контексте модели. Это даёт **воспроизводимость и экономию токенов**.

## Чем НЕ является

- Не визуальная RPG — графики намеренно мало
- Не игра с написанным сценарием — нет «главного квеста»
- Не сетевая — только одиночная
- Не emulator настолки — нет multiplayer-партии, мастер один и он ЛЛМ

## Целевая аудитория

В порядке приоритета:

1. **Автор и его друзья** — игра делается для себя в первую очередь
2. **Любители одиночных RPG** (BG3, Solasta, Pathfinder) — хотят бесконечную песочницу с правилами
3. **Экспериментаторы с LLM** — интересно посмотреть, как ИИ ведёт партию

## Платформа и стек (на старте)

- Windows / Linux desktop
- Pygame (прототип; в будущем возможен переезд на Godot — см. [ADR-0004](../tech/adr/0004-pygame-prototype.md))
- Python 3.x
- OpenRouter API (Gemini Flash Lite по умолчанию), позже vllm

## Что считать успехом v1.0

- Можно создать персонажа D&D 5e любого класса
- Можно играть несколько часов без багов и заметных галлюцинаций
- Бой работает по правилам D&D 5e
- Мир генерируется при выходе за пределы стартовой локации
- Можно умереть и начать заново
