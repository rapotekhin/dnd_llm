# Задания

Задания — данные пакета мира: `quests` в `world.json` ([формат](../tech/godot-client.md#пакеты-миров)). Выполняет и награждает движок (`XpRules`), мастер только описывает сцену ([ADR-0008](../tech/adr/0008-engine-decides-llm-narrates.md)).

## Формат (v0.5.4)

```json
"letter_to_ilva": {
  "title": "Письмо для Илвы",
  "description": "Бруно Хмель просит отнести запечатанное письмо жрице Илве…",
  "room": "brod-temple",
  "action": "Отдать Илве письмо Бруно",
  "xp": 300,
  "reward_cp": 0,
  "done_text": "Игрок отдал жрице Илве запечатанное письмо…"
}
```

- `title`, `description` — для журнала и для мастера (`snapshot.quests`).
- `room` + `action` — где и какой кнопкой задание выполняется.
- `xp`, `reward_cp` — награда, выдаёт движок.
- `done_text` — что произошло; мастер получает его в ходе `kind=quest` и описывает сцену, ничего не добавляя.

## Как работает сейчас

- Все задания известны с начала игры и видны в журнале.
- В комнате задания на панели есть кнопка `action`. Нажатие отмечает задание в `session.quests_done`, выдаёт опыт и монеты и просит мастера описать сцену.
- Мастер видит список заданий с отметкой «выполнено», но не может объявить задание выполненным или наградить за него: эффекта опыта у него нет.

Это проверка цикла «цель → награда → рост», а не система заданий.

## План

- **v0.6.2** — цепочка из 2–3 заданий: выдаёт NPC, шаги и условия проверяет движок (`quest_update`), награды из пакета; Пуща или шахта как подземелье с финальной сценой ([roadmap](../production/roadmap.md)).
- **M3** — задания из диалога как эффект, последствия через флаги мира.
- **M6** — генерация заданий вместе с миром.

## Открытые вопросы

- **Скрытые задания:** открывает их движок по триггеру (флаг, находка, разговор) или мастер предлагает, а движок принимает?
- **Провал:** у заданий нет состояния «провалено» — нужно ли оно в срезе?
