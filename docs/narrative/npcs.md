# NPC

## Источник данных

Стартовые NPC — `game/assets/ru/start_npcs.jsonl`.  
Структура NPC — `game/core/entities/npc.py`.

## Текущий список (старт)

В таверне «Серебряная Кружка» — 6 NPC, на рынке — 3 NPC. Подробности — в JSONL-файле.

## Атрибуты NPC

Ключевые поля:

- `id` — уникальный идентификатор (UUID или человеческий, e.g. `mkt-npc-001`)
- `name` — имя
- `role` — роль («бармен», «алхимик», «торговец»)
- `description` — короткое описание для контекста ЛЛМ
- Возможны полные D&D-атрибуты (HP, AC и т.д.) — для NPC, которые могут участвовать в бою
- Инвентарь — для торговцев

## Архетипы

Сейчас архетипы не формализованы. Каждый NPC уникален в JSONL.

В будущем стоит выделить категории, чтобы:
- Автогенерация NPC через `NpcBuilder` могла выбирать архетип
- Тон диалога подбирался от архетипа

Кандидаты:
- **Бармен / Хозяин таверны** — нейтральный информатор
- **Торговец** — расчётливый, готов к сделке
- **Стражник** — формальный, с мотивом порядка
- **Авантюрист / Наёмник** — потенциальный союзник
- **Местный житель** — источник слухов и локальных квестов
- **Антагонист** — конфликтная сторона

## Память NPC

Сейчас NPC **не помнят разговоров между сессиями диалога**.  
Контекст — только через `location_history_summary`, что неточно (несколько NPC в одной локации).

Это ограничение. См. [systems/social.md](../design/systems/social.md) → открытые вопросы.

## Ключевой NPC: ГМ-агент

Технически это не NPC, но стоит упомянуть. В контексте каждого режима ЛЛМ играет:

- **В exploration** — за ГМ (нарратор, описывает мир, вызывает броски)
- **В social** — одновременно за ГМ (наррация сцены) и за конкретного NPC (реплики)
- **В trade** — за NPC-торговца с механической поддержкой движка
- **В combat (план)** — за ГМ + всех противников

См. [dm-style.md](dm-style.md) для стиля ГМ.
