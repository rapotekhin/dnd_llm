# Паритет Godot-версии с прототипом v0.3.1

Чеклист v0.5.4 ([roadmap](roadmap.md) M1): всё, что умел pygame-прототип (`legacy/`, v0.3.x), есть в Godot-клиенте или сознательно отложено. После этой проверки `legacy/` удалён из репозитория; он остаётся в истории git (последний коммит с ним — v0.5.3, `9b43519`).

## Регрессии B1–B29

Спецификация из `legacy/tests/test_regressions_v031.py` и `_v033.py` перенесена в gdUnit: `test/core/test_regressions_v031.gd` (B1, B4, B8–B11, B14, B17–B19), `test_trade_rules.gd` (B13, B16), `test_level_up.gd` (B5–B7), `test_character_rules.gd` (B24: КД по доспеху, щит, стартовое снаряжение надето), промпты B25, B26, B29 — тесты бэкенда и золотые сценарии. B2 (состояние экранов при ресайзе) и B15 (выражения костей от модели) не воспроизводятся по устройству: экраны строятся из `GameState`, кости бросает движок по таблицам.

## Что ещё лежало в `legacy/`

- **SRD 5e (JSON API 2014)** — источник для `tools/srd_import.py`, перенесён в `tools/srd/source/2014/`.
- Стартовые локации и NPC (`assets/ru/*.jsonl`) — заменены пакетом мира «Сумеречная Марка».
- Скрипт локализации RU/EN, Langfuse-тест, ноутбуки, playtest-драйвер pygame — не нужны Godot-версии.
