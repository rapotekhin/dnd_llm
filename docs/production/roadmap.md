# Роадмап

> Этапы и версии проекта. Обоснование, баги B1–B21 и архитектура — в [review-2026-10.md](review-2026-10.md). Конкретные таски и техдолг — в [backlog.md](backlog.md).

## Текущий статус (октябрь 2026)

**Версия:** `0.3.1` (pygame) — в работе, фикс багов перед переездом.

**Что работает:**
- Создание персонажа (расы, классы, заклинания, предыстория) и поднятие уровня
- Exploration с ЛЛМ-ГМ (describe / actions / resolution), social, trade
- Перемещение между комнатами и локациями, сохранение и загрузка (10 слотов)
- Локализация RU (EN частично)

**Что не работает:**
- ❌ ЛЛМ не может менять мир: нет инструментов для HP, XP, предметов, монет, квестов
- ❌ Бой — пустой файл; смерть и рестарт
- ❌ Отдых, трата ячеек, видимые броски, проверки с бонусом мастерства
- ❌ Автогенерация мира

**Решено:** игра переезжает на Godot, ЛЛМ-логика выносится в отдельный Python-бэкенд (OpenRouter, позже vLLM). Архитектура — [review-2026-10.md §5](review-2026-10.md#5-архитектура-godot--python-llm-бэкенд).

## Принципы планирования

- **Одна версия = одна законченная фича, играбельная в плейсхолдерах** (как в hive_world_shop).
- **M1 — переезд без новых механик.** Та же игра на новой архитектуре, но правила и контракты сразу правильные: кубики и проверки — в движке.
- **Новые фичи (M2+) — только после паритета.**
- Каждый исправленный баг — регрессионный тест. После переезда он переписывается на новой стороне.
- Перед новым M-этапом закрываем критический техдолг.

## Этапы

- **M0** — решения и спайки, без кода игры
- **M1** — переезд: фикс багов → Godot → Python-бэкенд → тесты → перенос функционала
- **M2** — мир меняется (эффекты, память NPC, отдых)
- **M3** — бой · **M4** — рогалик-цикл · **M5** — генерация мира · **M6** — полировка и 1.0

## Инструменты разработки (параллельно, по образцу hive)

| Инструмент | Зачем |
|---|---|
| Журнал команд + реплей | Воспроизвести баг вместе с ответами ЛЛМ из кассеты (Godot пишет и `turn.result`, реплей идёт без бэкенда) |
| Бот-игрок на mock-ЛЛМ | Прогон 100 ходов без денег: инварианты (HP ≤ max, монеты ≥ 0, комната существует) |
| Eval-прогон на реальной модели | `llm_server/evals`: сравнение моделей (OpenRouter vs vLLM) и промптов по «золотым» сценариям, цена и задержка за ход |
| Контрактные тесты | Схемы из `contract/` против обеих сторон в CI |
| `validate_data.py` | Ссылки между SRD-данными, локализацией, стартовым контентом |
