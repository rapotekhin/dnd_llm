# Роадмап

> Высокоуровневые этапы развития проекта. Конкретные таски и техдолг — в [backlog.md](backlog.md).

## Текущий статус (май 2026)

**Что работает:**
- Создание персонажа (полное D&D 5e — расы, классы, заклинания, предыстория)
- Поднятие уровня (с выбором features, ASI, новых заклинаний)
- Exploration с ЛЛМ-ГМ (3 агента: describe / actions / resolution)
- Social — диалоги с NPC
- Trade — торговля с NPC
- Перемещение между комнатами и локациями
- Сохранение/загрузка (10 слотов)
- Локализация RU (EN частично)

**Что не работает:**
- ❌ Combat — пустой файл
- ❌ Автогенерация мира (builders есть, но не подключены к ЛЛМ)
- ❌ Смерть и рестарт (рогалик-логика)
- ❌ Динамические квесты

## Этапы

### M1 — Полировка прототипа (где мы сейчас)

Цель: стабильный демо-цикл «создать → играть в стартовой локации → сохраниться».

- [x] Базовый exploration loop
- [x] Social и trade
- [x] Level up
- [ ] Поправить технический долг по UI (z-order закреплён, но переходы иногда хрупкие)
- [ ] **Combat (минимальная версия)** — хотя бы атака мечом, hp тика, смерть

### M2 — Open world (главная веха)

Цель: реализовать ключевой USP — бесконечный мир.

- [ ] **Tools для ЛЛМ:** `create_npc`, `create_location`, `create_room`, `create_quest`, `create_treasure`
- [ ] Подключить `LocationBuilder` / `NpcBuilder` к exploration-агенту
- [ ] Логика «выход из карты» — когда игрок идёт за пределы известного, ЛЛМ генерирует новую локацию
- [ ] Связность регионов (леса вокруг города ≠ пустыня)

### M3 — Полный бой

Цель: пошаговый бой по 5e.

- [ ] Combat UI screen
- [ ] Initiative tracker, очередь ходов
- [ ] Action / Bonus action / Movement / Reaction
- [ ] Заклинания в бою (concentration, spell slots)
- [ ] AI противников через ЛЛМ + tools
- [ ] Death saves, стабилизация
- [ ] Возможный multiclassing

### M4 — Рогалик-цикл

Цель: смерть имеет значение, мир сбрасывается.

- [ ] Экран смерти
- [ ] Рестарт с сохранением мета-прогресса (если решим иметь)
- [ ] Заслуги / достижения по забегу

### M5 — Полировка и контент

## Принципы планирования

- Не делаем больше одной фичи M-этапа за раз
- Перед началом нового M-этапа — закрываем критический техдолг
- Combat не блокирует автогенерацию (M2) — можно делать параллельно или после
