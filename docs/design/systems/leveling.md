# Leveling Up

Поднятие уровня персонажа по правилам D&D 5e.

## Триггер

- Кнопка **«Персонаж»** в главном экране подсвечивается **золотым**, если `player.xp >= xp_required_for_next_level`
- Игрок открывает `LevelUpScreen` (создаётся on-demand в `Game._handle_screen_result()`)

Проверка возможности — в `core/utils/level_up_utils.py`.

## Что доступно на уровне

Зависит от класса. Возможные варианты:

- **+1 уровень** к Hit Dice / HP
- **Новые features** из таблицы класса
- **Subfeatures** (если новая feature предлагает выбор подопции)
- **Ability Score Improvement** (на 4, 8, 12, 16, 19 уровнях)
- **Новые заклинания и заговоры** (с лимитами 5e: known/prepared)
- **Новые proficiency choices**
- **Class-specific счётчики** обновляются (`action_surges`, `sorcery_points`, и т.д.)

## Технически

- `core/builders/level_up_builder.py` — содержит класс `LevelUpBuild`, который аккумулирует выбор
- `LevelUpScreen` (`level_up_screen.py`, 1222 строки) — UI с подэкранами для каждого этапа
- Финальный шаг — экран **подтверждения**, после которого `Character` обновляется

## Источник правил

Так же как character creation — данные о классах из `dnd-5e-core`.

## Открытые вопросы

- **Multiclassing** — не реализован. Нужен ли? D&D 5e позволяет, но усложняет UI.
- **Откат** — что если игрок выбрал и закрыл экран? Сейчас логика «всё или ничего», возможно надо сохранять промежуточное состояние.
