# Combat (планируется)

> ⚠️ **Не реализовано** в v0.5.4. Минимальный бой — v0.6.1, тактический — M4 ([roadmap](../../production/roadmap.md)). Документ — намерения, не описание готовой системы.

## Сейчас

- Атаку мастер описывает только началом (замах, реакция окружающих) — исхода удара нет, сцена продолжается (`_rules.md.j2`).
- Опасность — эффект `damage` по ступени тяжести (ловушка, падение, яд после провала), его числа считает движок. При 0 HP пока ничего не происходит — это v0.6.0.
- Опыт за бой уже готов в движке: `XpRules` и `rules.xp.by_cr`, но врагов нет.

## Видение

Пошаговый бой по 5e, в духе **Baldur's Gate 3 / Solasta**, но без сетки. Движок ведёт инициативу, HP, состояния и ячейки; мастер описывает; игрок выбирает действие кнопками — исключение из столпа свободы ради скорости и точности.

**Не хотим:** нарративный бой «опиши, как атакуешь» (размывает границу «движок решает, ЛЛМ рассказывает») и real-time с паузой.

## v0.6.1 — минимальный бой

- **Режим боя на экране игры:** инициатива, очередь ходов, атака и урон оружием, заговоры и заклинания с ячейками, криты, спасброски.
- **Враги** — статблоки монстров SRD (импорт CR ≤ 3 в `game/data/srd/`); рядовые ходят по простому ИИ движка.
- **Мастер** описывает раунд по итогам движка. Начало боя — `next_mode = combat` от мастера или встреча из пакета.
- **Встречи** в пакете мира (`encounters` в комнатах подземелий Марки); враги могут бежать и сдаваться.
- **Награда:** опыт по CR (`XpRules.combat_xp`), добыча через движок; боевые числа на листе (атака, урон, Ярость, Скрытая атака).
- Опирается на v0.6.0: ячейки тратятся, состояния работают, 0 HP — без сознания и спасброски от смерти, смерть — экран итогов.

## M4 — тактический бой (v0.8.0)

По [ADR-0010](../../tech/adr/0010-game-decisions-worlds-tone-combat-death.md) §4, поверх минимального боя:

- **Зоны** вместо сетки: вплотную / рядом (до 30 фт) / далеко / вне досягаемости; дальность и AoE — по зонам.
- **Действие / бонус / реакция**, концентрация в бою.
- **Противники смешанно:** рядовые — ИИ движка, боссы и разумные NPC — ЛЛМ выбирает из легальных действий движка (включая уговоры и бегство).
- **Наррация — раунд целиком:** сухие строки движка во время раунда, абзац мастера в конце.
- **Случайные встречи** по таблицам локаций и бюджету опыта DMG.

## Решения

- **Соло**, спутники — после 1.0. **Мультикласс** и уровни выше 5 — v0.8.1.
- Спасброски от смерти — по 5e. **Воскрешения для игрока нет** (домашнее правило); режимы смерти «История» / «Одна жизнь» — M5, простая смерть с экраном итогов — v0.6.0.
