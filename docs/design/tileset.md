# Тайлсет карты

Как рисуется карта места, какие земли и предметы уже нарисованы, какие генератор использует, но рисует чужой картинкой, и чего нет совсем. Начато в v0.8.4.43.16. Стиль — [art-style.md](art-style.md#карта-v084316), код — [godot-client.md](../tech/godot-client.md) («Земля карты»), понятие — [concepts.md](concepts.md) («Земля карты»).

## Как устроено

**Два слоя.** Клетка карты — символ из `cells` в [`layouts.json`](../../game/data/layouts.json): стена, пол, вода, дерево. Его правила (проходимость, видимость) не меняются. Над ним — **земля**: что под ногами (трава, доски, брусчатка), и **предмет**: что стоит на клетке (дерево, валун, стол, дверь). Землю и предмет выбирают данные `grounds`, а не код:

| Поле `grounds` | Что задаёт |
|---|---|
| `cells` | землю по символу клетки; строка — для любого места, словарь — по ключам места: его вид (`temple`, `dunes`…), виды его семьи, форма (`open`, `building`, `tunnels`) и `*` для прочих, самый точный первым (`LayoutGen.ground_keys`, v0.8.4.43.20). Символа нет — берётся строка `.` |
| `order` | порядок земель снизу вверх: на стыке верхняя ложится поверх нижней |
| `sharp` | земли, которые держат границу клетки (стена, крыша), со скосом и тенью на юг и восток |
| `props` | предмет на клетке по символу и тем же ключам места (`B` в руинах — обломки) |
| `size` | размер предмета в клетках (дерево — 1,7) |
| `patches` | пятна другой земли поверх пола по тем же ключам (берутся строки первого ключа, у которого они есть; пустой список — без пятен): `share` и `cell` — пятна по сиду карты, `near` и `width` — кайма вокруг клеток символа (пляж вокруг воды) |
| `repeat` | сколько клеток покрывает одна текстура |
| `colour` | цвет земли, пока у неё нет текстуры |
| `edges` | пары земель с нарисованным краем: `low` и `high` |
| `edge_layout` | 5×5 углов листа краёв: 1 — верхняя земля; каждое окно 2×2 — один из 16 случаев |
| `edge_band` | ширина полосы рисунка вокруг линии края |

**Двойная сетка (dual grid).** `MapGround` складывает землю, предмет и поворот двери каждой клетки в маленькую текстуру. Шейдер [`map_ground.gdshader`](../../game/ui/components/map_ground.gdshader) решает цвет точки по четырём клеткам, чьи центры стоят вокруг неё. Поэтому земли сходятся не по границе клетки, а неровной линией между центрами, и угловых плиток рисовать не нужно: форму края даёт маска с шумом, текстура у каждой земли одна. Острые земли (стена, крыша) остаются на своей клетке. Предметы соседних клеток могут заходить на эту (крона дерева). В том же проходе — плавный туман невидимого и подсветка под надзором. Сетка клеток видна только в бою.

**Генерация карты под двойную сетку.** Одиночная клетка земли превращается в маленькое пятнышко, поэтому генератор кладёт землю пятнами: строка `scatter` вида с `blob: true` — порог по шуму двух октав (`LayoutGen.blobs`) и чистка одиночек (`_despeckle`). После дорог и домов `_tidy` убирает одиночки ещё раз. Предметы (деревья, валуны) разбрасываются по одному, как раньше. Пруд — с берегом по шуму. Здание на открытой карте — стена по краю и крыша `r` внутри.

**Картинки.** Рисует FLUX 3 Klein через OpenRouter, около $0.009 за кадр:

```bash
python tools/tiles/gen_tiles.py draw                    # все задания tiles.json по 3 варианта (--only id,id; --force перерисовать)
tools/anima/.venv-matte/Scripts/python.exe tools/tiles/gen_tiles.py matte   # предметы вырезает BiRefNet
python tools/tiles/gen_tiles.py sheet                   # build/tiles/sheet_ground.png (земля 2×2 — виден шов), sheet_props.png
python tools/tiles/gen_tiles.py install                 # tools/tiles/picks.json → game/assets/tiles/{ground,props}/<id>.png
```

**Картинки не в git.** `game/assets/tiles/` в `.gitignore`: их рисует и ставит `gen_tiles.py` у себя, а в репозитории лежат промты (`tiles.json`) и выбор (`picks.json`). Без картинок карта рисуется цветами `grounds.colour`; сборка (`build_game.py`) берёт те, что стоят локально.

Промты — [`tools/tiles/tiles.json`](../../tools/tiles/tiles.json): общий стиль земли и предмета плюс предмет кадра. Землю FLUX рисует почти ровной, но не бесшовной: скрипт смешивает кадр с ним же, сдвинутым на половину (`seamless`), — 512 px. Предмет — 256 px с прозрачным фоном.

**Как добавить землю или предмет.**

1. Строка в `tools/tiles/tiles.json` (`ground` или `props`), `draw` → `sheet`, выбрать вариант в `picks.json`, `install`.
2. Земля: её id в `grounds.order` на своё место по высоте, цвет в `colour`, клетка или форма места в `grounds.cells`. Если край должен быть ровным — id в `sharp`. Предмет: строка в `grounds.props` и размер в `size`.
3. Если новая земля нужна пятнами по виду места — строка `scatter` с `blob: true` и новым символом клетки в `cells` либо `patches` по форме.
4. Тест `test_every_square_has_a_ground_of_the_order_and_every_cell_one_of_its_own` проверит, что у каждого символа есть земля, а у предмета — размер.

Земля без текстуры рисуется своим цветом из `colour`, так что данные можно завести раньше картинки.

**Нарисованный край пары земель** (v0.8.4.43.17). Пара — строка `grounds.edges` и, если нужно, своя фраза стыка в `tiles.json` → `edges` (`water__grass`: «травянистый берег с полосой мокрой земли»). `gen_tiles.py draw --only water__grass` строит маску пары на углах `edge_layout` (нижняя земля синяя, верхняя зелёная) и отдаёт её FLUX как образец (`input_references`): он рисует весь лист 4×4 одним кадром, поэтому свет и тон у плиток общие. Линия маски кладётся в альфу листа. `sheet` показывает лист с сеткой плиток, `install` кладёт его в `assets/tiles/edges/`. В игре от листа берётся только полоса вокруг линии, внутри — обычные текстуры земель: без этого целые плитки травы или воды дают шахматку тона (проба 2026-11-12).

## Что нарисовано

**Нарисованные края** (`game/assets/tiles/edges/`): `water__grass` (берег с мокрой землёй), `water__dirt` (илистый берег), `water__mud` (болотный край с камышом).

**Земли** (`game/assets/tiles/ground/`), по порядку слоёв:

| id | Где | Символы и места |
|---|---|---|
| `pit` | яма, провал | `o` |
| `still_water` | тёмная стоячая вода | `~` в пещере, шахте и болоте |
| `water` | вода, пруд, река | `~` |
| `mud` | грязь, заросли | `%` |
| `reeds` | камыш в болотной воде | `%` на болоте |
| `farmland` | пашня бороздами | `%` в поле |
| `dirt` | тропа, вытоптанная земля, земляной пол | `,`, `patches`, `.` в кузнице |
| `sand` | песок | `.` в пустыне и на арене, пляж у воды на берегу |
| `thorns` | песок с колючкой | `%` в пустыне |
| `ice` | лёд и наст | `%` на снежном поле |
| `snow` | снег | `.` на снежном поле |
| `stony` | каменистая земля гор | `.` в скалах (и в Подземье) |
| `scree` | осыпь | `%` и пятна в скалах |
| `grass` | трава | `.` на открытой карте |
| `tall_grass` | высокая трава | `%` в холмах и в лагере |
| `cobble` | мощёная дорога | `=` |
| `cave` | пол пещеры и шахты | `.` в пещере |
| `flagstone` | каменные плиты пола | `.` в храме, ратуше, тюрьме |
| `planks` | доски пола | `.` в прочих зданиях |
| `rock` | скальная стена | `#`, `D` в пещере и шахте |
| `wall` | каменная кладка | `#`, `w`, `D` |
| `roof` | крыша дома на открытой карте — гонт | `r` |

**Предметы** (`game/assets/tiles/props/`):

| id | На клетке |
|---|---|
| `tree` | `T` — крона дуба, 1,7 клетки |
| `boulder` | `B` на улице и в пещере |
| `rubble` | `B` в руинах — обломки кладки |
| `table` | `B` в здании |
| `door` | `+`, повёрнута по стене |

Кодом поверх земли: окно (стекло поперёк стены) и опасная клетка `^` (красная пометка). Поверхности боя (масло, огонь, паутина, лужи) рисуются отдельно, по `surfaces` из [`anims.json`](../../game/data/anims.json).

## Есть в генерации, но рисуется чужой картинкой

| Что | Сейчас | Нужно |
|---|---|---|
| Погреб и подвал | доски или пол пещеры | каменные плиты: пол по **роли** комнаты, а не только по виду места |
| `B` внутри здания | всегда стол | стол, стойка, кровать, бочки, полки — по чанку; сейчас у всех один символ |
| Метки чанков: `hearth`, `forge`, `bench`, `altar`, `stage`, `stall`, `bed`, `vein`, `water` | не нарисованы | предмет на клетке метки: очаг, горн с наковальней, верстак, алтарь, помост, прилавок, кровать, рудная жила, колодец |
| Опасная клетка `^` | красная пометка | ловушка, видимая только найденной |
| Яма `o` | тёмная текстура | нарисованный край: обрыв, осыпающийся край |
| Выходы | золотые квадраты | свой рисунок: проём, тропа за край, лестница |

## Чего нет ни в генерации, ни в рисунке

- **Мост и брод.** Путь вида `ford` есть в `rules.ways.kinds`, а клетки и рисунка для него нет.
- **Лестница** внутри здания (переход `stairs` у «Обустройства» есть, на карте не видна).
- **Частокол, забор, живая изгородь** — граница двора и деревни. Частокол как проект поселения есть в пакете мира (`worlds/frontier/world.json`), на карте его нет.
- **Грядки, огород** (пашня как трудная местность поля есть).
- **Кусты** как непроходимое препятствие ниже дерева.
- **Мелкая и глубокая вода** раздельно: сейчас вода одна, стоит 2 движения.
- **Внутреннее убранство:** ковры, рогожа, солома на полу.
- **Могилы и кладбище**, **рельсы и крепь шахты**, **лава** для Подземья.

## Что сделать дальше

План автора по картам — раздел роадмапа [v0.8.4.45](../production/roadmap.md#v08445--карта-тайлсет-чанки-и-предметы-на-клетках-просьба-автора-2026-11-12): чанки пещер рваной формы, открытые места из чанков, места предметов со связями, предметы в несколько клеток, веб-редактор чанков, много предметов. Ниже — порядок по тайлсету. Чанки рисуются в `tools/editors/chunks.html` с картинкой игры рядом: новая земля или предмет видны там сразу после `install`.

По порядку пользы:

1. **Пол по роли комнаты:** погреб — плиты, не доски; ключ роли в `ground_keys`.
2. **Свои края новых земель** — листом по маске: вода с песком (пляж), стоячая вода с камышом (скала с полом пещеры — в п. 6).
3. **Стоячая вода без повтора:** у выбранного варианта видны тёмные пятна через три клетки — перерисовать с ровным тоном.
4. **Предметы меток:** очаг, горн, верстак, алтарь, прилавок, кровать, жила, колодец — `props` по метке, а не по символу.
5. **Разные блоки в здании:** свои символы чанков или метки для стойки, кровати и бочек вместо одного `B`.
6. **Ещё нарисованные края** — тем же листом по маске: яма с каждой землёй (обрыв), скала с полом пещеры, брусчатка с травой и тропой. Вода с травой, тропой и грязью уже нарисованы (v0.8.4.43.17).
7. **Выходы и мост с бродом:** клетки и рисунки.
8. **Повторы:** 2–3 варианта текстуры одной земли и смешение по шуму, чтобы на большой поляне не было видно повтора каждые 3 клетки.
