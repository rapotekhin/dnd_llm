# Геймплей: общий обзор

## Игровая петля

Высокоуровневый цикл одной игровой сессии:

```
┌─ Создание персонажа (один раз)
│
└─→ Главное меню
     │
     └─→ Старт в таверне «Серебряная Кружка» (Невервинтер)
          │
          ├─→ Exploration: ЛЛМ описывает сцену → даёт 2-4 варианта действий → ждёт выбора
          │       │
          │       ├─→ выбор «Поговорить с X» → Social mode
          │       ├─→ выбор «Купить у X» → Trade mode
          │       ├─→ выбор «Пойти в комнату Y» → смена комнаты → Exploration
          │       ├─→ выбор «Атаковать» → Combat mode (НЕ РЕАЛИЗОВАНО)
          │       └─→ любой другой выбор → Exploration с наррацией исхода
          │
          └─→ Уровень → Level up screen (когда хватает XP)
```

Игрок может в любой момент открыть: инвентарь, лист персонажа, журнал квестов, карту, способности.

## Что игрок делает за 30 минут (типично)

Аналогично настольной D&D, но в одиночку:

1. **70%** — exploration и social: разговоры с NPC, осмотр комнат, проверки навыков, мелкие квесты
2. **20%** — torговля и менеджмент инвентаря
3. **10%** — бой *(когда будет реализован)*

Бой не доминирует — это редкое, но значимое событие, как в D&D-сессиях.

## Состояние игрока vs состояние мира

| Что | Где живёт |
|---|---|
| Персонаж (HP, XP, инвентарь, заклинания) | `Character` (наследник `dnd_5e_core.Character`) |
| Текущая локация / комната | `MainGameState.current_location_id`, `current_room_id` |
| NPC и их данные | `MainGameState.npcs` |
| Локации, уровни, комнаты | `MainGameState.locations`, `levels`, `rooms` |
| Квесты | `MainGameState.quests` |
| История событий в локации (для контекста ЛЛМ) | `Location.location_history_summary` |
| Текущий разговор / сцена | в потоках gameplay-модулей (не сохраняется) |

Сохраняется всё в `~/AppData/Local/DnD_LLM_Game/saves/save_{1..10}.pkl` (Windows).

## Прогрессия

- Уровни: 1-20 (стандарт D&D 5e)
- Темп: типично D&D — на ранних уровнях 1-2 сессии на уровень
- Источники XP: бой *(когда будет)*, квесты, milestone leveling — обсуждается

## Open world и автогенерация

В стартовой версии — три фиксированные локации (таверна, рынок, пещеры).  
Цель: **бесконечный мир, генерируемый ЛЛМ** при выходе за границы известного:

- Игрок идёт «на дорогу из города» → ЛЛМ через `LocationBuilder` создаёт новую локацию
- ЛЛМ создаёт NPC, лут, квесты через соответствующие builder'ы

Сейчас builder'ы существуют (`core/builders/`), но не подключены к ЛЛМ как tools.  
Это ключевая работа, см. [production/roadmap.md](../production/roadmap.md).
