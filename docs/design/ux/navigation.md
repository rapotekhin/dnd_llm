# Навигация и UI-конвенции

## Глобальная навигация (из MainScreen)

Кнопки доступа к подэкранам — на главном экране игры:

| Кнопка | Открывает |
|---|---|
| Инвентарь | `InventoryScreen` |
| Персонаж | `CharacterScreen` (золотая, если доступен level up) |
| Способности | `AbilitiesScreen` |
| Журнал | `JournalScreen` (квесты) |
| Карта | `MapScreen` |
| Настройки | `SettingsScreen` |

## Конвенции отрисовки (z-order)

После проблем с перекрытием в v0.2.0 закреплён порядок:

1. **Фон** (background)
2. **Контент экрана** (panels, lists, text)
3. **Кнопки навигации** (всегда поверх контента, но клиппируются от перекрытий)
4. **Модальные окна** — после всех элементов, с **затемняющим overlay**
5. **Тултипы** — последними, поверх всего

Клиппирование текста в панелях — обязательно (введено в 0.2.0).

## Конвенции компоновки

- **Адаптивное позиционирование** — элементы рассчитываются от размеров экрана, не от фиксированных координат
- **Списки с прокруткой** — длинные списки (заклинания, NPC, мировоззрения) ограничены по высоте
- **Метки выше полей ввода** (а не слева) — экономит ширину

## Языки

Все строки UI — через `loc.t("ключ")`. Перевод в `game/localization/`. Текущие языки: RU (полный), EN (частичный — техдолг).

Смена языка в настройках → пересоздание всех экранов.

## Разрешение и режим

- Дефолт: 1280×720 windowed (RESIZABLE)
- Поддерживается фуллскрин и произвольный resize (через `pygame.VIDEORESIZE`)
- Workaround в `Game._on_settings_applied()` для смены fullscreen→windowed на некоторых системах: `pygame.display.quit() + init()`

## Что в UI не определено и нужно решить

- **Стиль и цветовая палитра** — нет художественного гайда, всё «как получилось». См. art-style ниже
- **Иконки** — сейчас единственная картинка `character_placeholder_icon.jpg`. Нужны иконки для предметов, школ заклинаний, статусов
- **Шрифты** — какой основной, какой акцентный? Поддержка кириллицы — обязательна
