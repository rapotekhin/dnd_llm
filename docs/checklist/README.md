# Чек-лист ручной проверки

`test-checklist.xlsx` — всё, что можно проверить руками, по листам: обычные и магические предметы, монстры, способности (классовые и черты рас), заклинания, состояния (испуг, слепота… и статусы заклинаний), сопротивления и иммунитеты, типы урона (по каждому: `dmg` без боя и `hit` по юниту с ожидаемым числом, крит, защиты, немагический удар по монстру с сопротивлением, `magic` и `silver`; кто наносит этот урон). В каждой строке — команда dev-консоли, которая кладёт это в игру (`give`, `spawn`, `feature`, `trait`, `spell`, `cond`, `resist` / `immune` / `vulnerable`, `hit`, `dmg`, на юнита — `@<цель> …`), и колонки автора: «Проверено», «Есть баг», «Исправлено», «Комментарий».

Консоль — `~` в игре с флажком «Режим разработчика» в настройках или с `--dev`; команды и как они устроены — [tech/godot-client.md → «Отладка»](../tech/godot-client.md#отладка).

Собрать заново после смены данных (отметки и комментарии остаются у своих строк по листу и id):

```bash
uv run --with openpyxl python tools/checklist.py
```
