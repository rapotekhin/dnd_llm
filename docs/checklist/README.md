# Чек-лист ручной проверки

`test-checklist.xlsx` — всё, что можно проверить руками, по листам: обычные и магические предметы, монстры, способности (классовые и черты рас), заклинания, состояния (испуг, слепота… и статусы заклинаний), сопротивления и иммунитеты, у предметов — колонка «Как проверить»: шаги по свойствам вещи (надеть, настроиться, затем проба: `dmg` силовым уроном для броши защиты, `hit … crit` для адамантина, «Использовать» с ожидаемым числом хитов, бросок колбы, заряды палочки), типы урона (по каждому: `dmg` без боя и `hit` по юниту с ожидаемым числом, крит, защиты, немагический удар по монстру с сопротивлением, `magic` и `silver`; кто наносит этот урон). В каждой строке — команда dev-консоли, которая кладёт это в игру (`give`, `spawn`, `feature`, `trait`, `spell`, `cond`, `resist` / `immune` / `vulnerable`, `hit`, `dmg`, на юнита — `@<цель> …`), и колонки автора: «Проверено», «Есть баг», «Исправлено», «Комментарий».

Колонки «Автотест» и «Автотест: что проверено» — проверка каждой строки самим движком (`ChecklistProbe`, `game/core/debug/checklist_probe.gd`). Для каждой строки создаётся свежая игра. Вещь выдаётся, надевается и настраивается, у неё проверяются удар, КД, свойства, использование, еда, вода, свет, инструмент и сумка. Заклинание колдуется в бою по врагу, на себя или по клетке, пока не подействует, и ещё раз вне боя. Монстр бьёт героя каждым действием. Состояние ложится на героя и на врага, затем проверяются его помехи и автопровалы. Защиты и типы урона проверяются пробой 8 урона. Статус строки — худший из шагов:

- **работает** — всё, что обещают данные и описание, движок сделал;
- **ошибка** — движок сделал иначе;
- **нет механики** — описание или данные обещают то, чего у движка нет (это бэклог);
- **через мастера** — только словами мастера;
- **без механики** — проверять нечего, кроме выдачи.

Шаги: «✓» — сделано, «✗» — ошибка, «○» — нет механики, «◇» — мастер, «·» — заметка.

Результаты лежат в `game/test/fixtures/checklist_probes.json`. Тест `test_checklist_probes.gd` падает, если строка сменила статус (что-то сломалось или появилось) или у движка нашлась ошибка. После правки движка или данных запусти проверки заново и пересобери чек-лист:

```bash
"$GODOT" --headless --path game -s res://tools/checklist_probes.gd          # все листы, ~30 с; можно назвать листы: -- "Заклинания"
```

Консоль — `~` в игре с флажком «Режим разработчика» в настройках или с `--dev`; команды и как они устроены — [tech/godot-client.md → «Отладка»](../tech/godot-client.md#отладка).

Собрать заново после смены данных (отметки и комментарии остаются у своих строк по листу и id):

```bash
uv run --with openpyxl python tools/checklist.py
```
