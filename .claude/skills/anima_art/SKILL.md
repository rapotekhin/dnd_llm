# anima_art

Как мы рисуем арт игры на Anima: иконки, портреты, элементы интерфейса. Всё, что выяснили пробами с автором (2026-11-10 … 11), чтобы не открывать заново.

## Когда срабатывать

- Нарисовать или перерисовать иконки, портреты, элементы интерфейса; ночной прогон на сервере
- Иконка или портрет вышли не тем (не тот пол, возраст, существо, мелко, обрезано)
- Отбор вариантов, установка в игру, правка `subjects.json`, `portraits.json`, `picks*.json`

**НЕ срабатывает на:** картинки событий мастера (`llm_server/src/llm_server/images.py`, свой промт на семью модели); вёрстку окон без рисунка (`godot_conventions`).

## Конвейер (`tools/anima/`, подробно — [README](../../../tools/anima/README.md))

| Файл | Где | Что |
|---|---|---|
| `make_jobs.py` | репо | задания из данных игры: `jobs/icons.json` (1007), `--portraits` → `jobs/portraits.json` (1308); `--describe` — описания, которых нет, пишет модель (центы); `reseed` из `picks.json` |
| `subjects.json` | репо, руками | что рисовать: теги Danbooru + одна фраза по `<kind>/<id>`; `key` — фон (`grey` для тёмного предмета) |
| `portraits.json` | репо, руками | таблицы внешности людей: раса (`tags`, `word`, `features` — строка или `{male, female, minor}`), возрасты, волосы, одежда |
| `anima_gen.py` | сервер | рисует только недостающее или изменившееся (рядом с вариантом `.txt` — промт; нет сырого кадра этой затравки — тоже рисует); `--style flat\|painted\|lines`, `--recut`, `--sheets`, `--ids`, `--only`, `--seeds` |
| `install.py` | репо | `picks.json` (`variant`, `redo`, `overlay`, `same` — иконка с выбранного варианта другой: то же умение на другом уровне, тот же стиль боя у двух классов; `drawn` — иконка целиком кодом из `overlays.ICONS`, где модель заливает простую геометрию: d20 и лист в окне персонажа) → `game/assets/icons/<kind>/<id>.png`; `--jobs …portraits.json` → `game/assets/portraits/…` |
| `overlays.py` | репо | знак поверх иконки кодом (пацифик на «Не убивать»; у золотых линий интерфейса `peace_gold` — золотой на тёмном круге; `strike` — красная черта через всю иконку: «Ослеплён», «Оглох»): модель символы и перечёркивание коверкает |
| `pick.py`, `pick.html` | дома | выбор вариантов в браузере: одна страница `http://127.0.0.1:8791/`, кнопка на каждый нарисованный набор (`SETS`: папка, файл выбора и вид заданий — действия из `out_painted_flux/` в `picks_flux.json`, прочие в `picks_painted.json`; стиль «линии» — свои вкладки `lines_spells`… из `out_lines/` в `picks_lines_icons.json`), варианты иконки рядом (до шести), щелчок пишет `variant`; галочка «перерисовать» с заметкой автора пишет `redraw` (`kind/id` → что не так; не `redo`, install.py её не читает), `--marked` печатает отмеченные — их и перерисовывать, не спрашивая по одной; `#acts` — открыть на виде, `?ids=a,b` — только перерисованные; перезапуск после новых иконок |
| `matte.py` | дома, `.venv-matte` (torch, CUDA) | вещи семейства `object` вырезает из сырых кадров BiRefNet (~0,7 с кадр на RTX 3050 Ti); запускать после каждого прогона с сервера |
| `ui/guides.py`, `ui/paint.py`, `ui/mock.py` | репо | элементы интерфейса: свои направляющие → ControlNet → макет с нарезкой на 9 частей |

`out/`, `out_painted/`, `out_ui/` в git не идут; сырые кадры 768 px хранятся — любой вырез переделывается `--recut` без перерисовки.

Forge: `--api`, чекпойнт `anima-aesthetic` (v1.1), модули `qwen_image_vae.safetensors`, `qwen_3_06b_base.safetensors`; дома — проброшенный порт `127.0.0.1:7860`. 768 px, CFG 4.5, ER SDE; 20 шагов ≈ 19 с, 24 ≈ 22 с.

## Промт (карточка Anima)

Качество в начале → теги Danbooru строчными с пробелами → одна-две простые фразы → хвост стиля. D&D-названий модель не знает, текст рисует плохо.

- **Иконки, плоские** (`flat`, `out/`): «flat color, minimalism, icon», 2–3 цвета. A/B 2026-11-10: тёмный фон без тега — предмет крупнее и смелее всего; серый/зелёный фон его уменьшает; «dark outline» — толстые контуры.
- **Иконки, живописные** (`painted`, `out_painted/`, автор 2026-11-11 — к портретам и интерфейсу) рисуются **семействами, как в BG3** — разбор в [docs/design/ux/bg3-icons.md](../../../docs/design/ux/bg3-icons.md), вид → семейство в `FAMILY` (`anima_gen.py`):
  - `object` (вещи): «painted as a small illustration in a soft painterly style… light from the upper left… large and centered and fills almost the whole square, on a plain flat {bg} background with no vignette»; негатив + `flat color, minimalism, vector art, vignette, gradient background, small object`. Без «large… almost the whole» выходило мелко, виньетка портила вырез.
  - `glyph` (заклинания): «emblem of thin glowing lines… on a square tile of dark brown rough cracked stone». Модель рисует **плитку камня со скруглёнными углами на чёрном** и яркий залитый светящийся знак — так и оставили: в 64 px читается лучше всех (выбор автора из пяти вариантов 2026-11-11). Чёрное вырезается, камень во весь кадр остаётся квадратом (`tile`). Цвет знака — из описания (урон, потом школа). Плитку с наклоном выровнять при разборе (`--recut`).
  - `plate` (умения): тот же знак на «square plate of brushed silver-grey steel with a cool blue tint and a rivet in each corner» (выбор автора 2026-11-12): умение не спутать с заклинанием. Тёмная потёртая сталь сливалась с бурым камнем — нужна светлая; белый знак на светлой стали светится слабее, цвет знака задать в описании.
  - **Через OpenRouter** (`anima_gen.py --backend openrouter`, FLUX 3 Klein по умолчанию, ~$0.009 кадр, `out_painted_flux/`, `picks_flux.json`): тот же промт без негатива, сид не держится. Действия рисует FLUX (автор 2026-11-12): с тем же промтом он понял жесты, Anima — нет. Рамки интерфейса через него нельзя — нет ControlNet.
  - `ink` (действия): «a rough sketch of a few thick dark ink brush strokes with no fill… cropped by the frame where it comes in from the edge» на той же стали. Пробовали светящийся знак (непонятно), плоскую пиктограмму (голо), иллюстрацию (жесты мимо), белый мел (теряется на светлой стали), штрихи на тёмном без пластины — автор взял тушь. Жест — **руки в три четверти, входящие от нижнего левого края**, или предмет; ладонь анфас модель рисует как «стоп» и «дай пять», рука на вертикальном предплечье двусмысленна.
  - `bronze` (черты рас): знак заклинания на «square plate of polished warm bronze with a little green patina… and a rivet in each corner» — отличие от стали умений и действий (автор 2026-11-12).
  - `medal` (состояния): простой значок — «a thin polished gold ring around a dark flat round field… one simple bold emblem in its own bright colours with a thick dark outline, no shading» (автор 2026-11-12). Чеканная золотая монета давала знак золотом по золоту и много деталей; модель рисует зверя, где в описании нет предмета, — «Ничком» стало жёлтой стрелкой вниз, «Отравлен» — зелёной каплей с черепом. Всё должно помещаться в кольцо: торчащая стрелка сбивает круг выреза.
  - `gold` (кнопки интерфейса, `ui`): «one simple elegant line drawing in pale warm gold on a plain black background… only outlines with the inside of every shape left black» (автор 2026-11-12, к интерфейсу «линии»). Цвета сюжетов писались для живописных вещей — `uncolour` выкидывает их из промта, иначе «бледная роза компаса» заливалась. Вырез `gold`: яркость — прозрачность, всё в одно золото, вписано в квадрат с одинаковым полем. Действия этим золотом: предметы выходят, жесты рук — двусмысленные (кулак, молитва), автор оставил тушь.
  - **Стиль «линии»** (`--style lines`, `out_lines/`, `picks_lines_icons.json`; проба автора 2026-11-12, живописные не заменяет): заклинания, умения, действия и черты рас как кнопки `gold`, но в рамке — заклинание в золотом кольце со знаком цвета своей школы, умение и действие в золотом квадрате, черта расы в серебряном. **Модель рисует только знак** белыми линиями без рамки (семейство `sign`), **рамку и цвет кладёт код** (`lines`, таблица `LINES`): геометрию модель портит, а кодом рамка одна у всех, знак вписан внутрь, цвет — ровно `schools` из `icons.json` (`tint` задания, `make_jobs.py`), меняется `--recut` без перерисовки. Цвета школ — игровые и для линий: охра преобразования и янтарь вызова близки к золоту кольца, автор оставил их (2026-11-12). Свой `tint` в `subjects.json` — где виды различаются только цветом (десять драконьих предков: черты и умения). Где знак в линиях нужен другой, у сюжета свой `lines` (`tags`, `sentence`, `people` — знак с людьми, без `no humans`): живописный вариант не перерисовывается. Пометки автора 2026-11-13: лучей у заклинаний слишком много — луч рисовать тем, что он делает (луч холода — сапог во льду), а не лучом; знак должен называть свою суть (у кары — божественный сигил, у «Убийцы великанов» — великан). Действия и тут рисует FLUX (`out_lines_flux/`): на пробе у Anima «Помочь» — молитва, у FLUX — сцепленные предплечья. Волосяные линии знака код доводит до `SIGN_LINE` (`bolder`): иначе в 64 px знак пропадал рядом с рамкой.
  - `groups` — `object`, как предметы (серебряный рельеф, как навыки BG3, не вышел — автор взял вещи); `marks/*` — `flat`.
  - **Вырез — не цветом.** Живописный фон не ровный (бурый градиент, мягкая тень), а трещины плитки чёрные, как фон: заливка от края ела тёмные части вещи, оставляла тень и дырявила плитку (ночной прогон 2026-11-11). Плитка — по форме (`tile`: выпуклая оболочка того, что отличается от фона, выпрямлена, по своей рамке; камень во весь кадр — квадрат). Фон — не один цвет, а гладкая поверхность по краю кадра: под сталь модель кладёт синий градиент, и фон одним цветом оставлял синюю кайму; поверхность строится только по тем точкам края, что близки к фону (пластина, касающаяся края, не в счёт). Камень во весь кадр из гладких плит проходил за фон — его узнаёт текстура вне найденной плитки (`OUTSIDE`); медаль — круг по рамке плитки; вещь — дома моделью `matte.py` (BiRefNet, torch на видеокарте, своё окружение `.venv-matte`) — по своей рамке.
  - **Похожие** в 64 px (огненный шар и сфера, молния и ускорение, синие щиты, черепа, глаза) — разводить описанием по смыслу заклинания; одна форма разного цвета — можно оставить.
- **Портреты**: `score_7, safe`, бюст «head and shoulders… soft painterly shading, on a plain dark muted background»; детям и подросткам — негатив `loli, shota, child` (ребёнку без `child`) + `minor_neg`: ни декольте, ни косметики.
- **Тёмный предмет** — `key: grey` в описании: на тёмном фоне вырез съедает край.

### Уроки описаний (что ломало)

| Было | Вышло | Правка |
|---|---|---|
| `giant wolf spider` в тегах | волки | слово «wolf» убрать: «giant hunting spider, eight legs» |
| ящерица с `forked tongue` | змеи | «four legs, gecko», без языка |
| `no humans` у сатира, гарпии, спрайта | козёл, волосатая тварь | `solo, 1boy/1girl`, «a man's face…» |
| спрайт с `green skin` | гоблин с крыльями | «elfin face, pale skin, messy hair» |
| кентавр с «horse body» | мелкая фигурка в рост | «seen from the chest up» |
| «small», «tiny» во фразе | крошечный предмет | убрать, «big… fills the whole square» |
| d20 | куб | «icosahedron, many triangular faces, the number 20» |
| дварф «weathered face, thick neck» для всех | женщины — мужики, дети — взрослые | `features: {male, female, minor}` |
| символ (пацифик) или перечёркнутое моделью | кривой знак, черты нет | `overlay` в `picks.json`, рисует `overlays.py` |
| глиф «on a square tile of stone» | плитка со скруглёнными углами на чёрном, знак залит | автору понравилось больше «правильных» вариантов: не «чинить» то, что читается лучше; сравнивать в 64 px |
| глиф на «dim stone, subtle texture» | фон тише, но знак мельчает | не брать |

Системная причина (тег, слово, черта расы) → правка описания или таблицы; случайная неудача → `reseed`.

## Отбор и исправление

1. Листы: `--sheets` или свой лист по заданию — варианты **в том размере и форме, как в игре** (портрет — круг 64–96 px, иконка — ячейка 64–128). Живописные иконки автор выбирает сам на странице `pick.py` (так быстрее, чем выбор по листу): заклинание — где камень рельефнее, без похожих соседей.
2. Ищи: не тот пол или возраст, не то существо, мелко или в полный рост, обрезано вырезом, артефакты, тёмное на тёмном.
3. Системное — правь `subjects.json` / `portraits.json`, `make_jobs.py` (`--portraits`), та же команда `anima_gen.py` перерисует только изменившееся.
4. Случайное — `picks.json` → `reseed: {"portraits/people/elf/male/young__4": 401}` (иконкам — выбрать другой `variant`, третий вариант: `--seeds 11,22,33 --ids …`).
5. Лучший вариант иконки — `variant`, безнадёжные — `redo` (игра покажет заготовку или букву).

## Портреты

- Люди без классов: 9 рас × 2 пола × (6 возрастов × 5 + ребёнок × 1) = 558; монстры: 150 шаблонов × 5 = 750 (человек-шаблон — мужчина в нечётных, женщина в чётных).
- В игру идёт **лицо**: постоянная рамка `FACE = (0.14, 0.02, 0.86, 0.74)` из бюста, 256 px WebP (решение автора: поиск лица по светлому пятну пробовали — не нужен). Сменил рамку — `--recut`.
- Выбор лица в игре — `PortraitRules.of` (вариант по `hash(id)`, герой — свой выбор при создании); файлы `game/assets/portraits/people/<раса>/<пол>/<возраст>__<n>.webp`, `monsters/<шаблон>__<n>.webp`.

## Элементы интерфейса (пробы 2026-11-11, 2026-11-12)

- **Только свой рисунок.** Не брать картинки BG3 или другой игры в ControlNet/img2img: это их арт, производная в нашей игре (принцип автора — раскладка как в BG3, рисунок свой). Смотреть на них можно, копировать формы нельзя.
- Свои направляющие кодом (`ui/guides.py`): глубина (выпуклая кайма, утопленное поле) + линии (стык каймы и поля, внутренняя линия, угловой орнамент). Внешнюю линию по краю холста не рисовать — модель делает из неё светлую кромку.
- ControlNet LLLite: `anima-lllite-depth-1` 0.75 (до 0.8 шагов) + `anima-lllite-lineart-1` 0.55 (до 0.6), `module: None`, `Just Resize`. Ещё есть `scribble-1`, `inpainting-v2`, `pose-1`.
- **Баг Forge:** второй вызов LLLite ломает модель — любой запрос дальше отвечает 500 «'NoneType' object is not callable». Лечится `POST /sdapi/v1/unload-checkpoint`; `ui/paint.py` выгружает после каждого кадра. Не запускать вместе с другим заданием на том же Forge.
- Нарезка на 9 частей (углы как есть, края и середина тянутся), состояния кнопки — из одной картинки яркостью и тёплым свечением (`ui/mock.py`); `ui/preview.py` собирает экраны игры из деталей стиля «линии» по выбору автора (`ui/picks_lines.json`, деталь — свой сид) и выбранных иконок; на странице `pick.py` это вкладки «Рамки интерфейса» и «Превью». В игру их кладёт `ui/frames.py` (v0.8.4.43.23): по строкам `frames` в `game/data/icons.json` (деталь — `cut` и `scale`, файл — деталь и вид, стиль темы — файл) режет выбранные детали в `game/assets/ui/frames/<файл>.png`, а `UiTheme.skin` при старте кладёт их в тему как `StyleBoxTexture`; без файлов остаётся плоская тема. Украшения (v0.8.4.43.25) режутся по яркости: линия разделителя без ромба (`line`) и ромб отдельно (`mark`), кольцо целиком (`lit`) — их кладёт код игры (`UiTheme.adorn`, `Portrait`); `pad` детали — отступ её линии от края, его прибавляют к полям текста. После нового выбора рамок — `frames.py` и `--import`.
- Стиль — запись `STYLE` в `ui/paint.py`: теги, фраза на каждую деталь, хвост, добавка к негативу, семья направляющих (`heavy`, `thin`, `book`, `plate`). Пробовали `leather`, `wood`, `lines` (как BG3: тёмная панель в две тонкие золотые линии), `book` (как Pathfinder WotR: лист пергамента), `plates` (сталь с заклёпками вокруг камня, как наши иконки). **Автор выбрал `lines` (2026-11-12).**
- Детали `lines`: панели `window`, `button`, `accent`, `tab`, `card`, `field`, `cell` (9 частей) и украшения `crest`, `divider`, `ring` на чёрном (герб в игру не идёт: автор отказался от него поверх рамки, v0.8.4.43.26.1) (кладутся целиком, яркость — прозрачность, `mock.lit`).
- Уроки: «window» в промте — окно компьютера с заголовком (пиши «panel»); «страница книги» — раскрытая книга («one flat sheet»); орнамент посередине края растянется — только углы, гербик отдельной деталью; белое или чёрное поле вокруг рамки срезается заливкой от углов и маской по направляющей; акцентную кнопку модель красит как обычную — золото кладёт код; нарисованная рамка бывает шире направляющей — поле нарезки по кадру.

```bash
cd tools/anima && pip install pillow
nohup python3 anima_gen.py jobs/icons.json --style painted --steps 20 --only items,spells > painted.log 2>&1 &   # ~6 ч
nohup python3 anima_gen.py jobs/portraits.json --steps 24 > portraits.log 2>&1 &                               # ~8 ч на все
tail -f painted.log                           # [12/1186] items/longsword #1 19s, left ~6.1 h
```

Стиль «линии» (заклинания, умения, черты рас по три варианта — 1260 кадров, ~6,7 ч; действия дома через FLUX, `--backend openrouter --only acts`, ~$0.9):

```bash
nohup python3 anima_gen.py jobs/icons.json --style lines --steps 20 --only spells,features,traits > lines.log 2>&1 &
```

Время: кадров × 19 с (20 шагов). Остановленный прогон продолжается той же командой. Значки `marks/*` оставлять плоскими. Дома — `out*/` с сервера в `tools/anima/`.

## В игру

```bash
python tools/anima/install.py                                   # иконки по picks.json
python tools/anima/install.py --out tools/anima/out_painted --picks tools/anima/picks_painted.json
python tools/anima/install.py --jobs tools/anima/jobs/portraits.json
"$GODOT" --headless --path game --import
```

Иконка выбирается одним местом — `IconRules.of` по `game/data/icons.json` (`ui` — что рисовать, `buttons` — кнопка → иконка, `shared` — одна картинка за другую). Новая иконка интерфейса: строка в `icons.json → ui` + описание `ui/<id>` в `subjects.json`.

Коммит артом отдельно (`icons: …`, `portraits: …`, без версии). Большой push: `git -c http.version=HTTP/1.1 push`. Тест не должен зависеть от того, нарисованы ли файлы: направь корень на пустую папку (`test_portraits_v0844352.gd`).
